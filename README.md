## 四、协作约定（摘要）

- 变更走文档：策划案改动在文末追加变更记录，重大范围调整进会议与决策记录。
- 需求要可验收：不写"手感好"，写可判定的条件。
- 合规先行：第三方素材只使用 CC0 / CC BY 4.0 / CC BY-SA 4.0 / MIT / BSD / Apache-2.0 / OFL 等开放许可；使用 AI 须如实记录工具、用途、生成内容与人工修改。
- 分工边界：策划写"要什么、什么算好"，程序写"怎么做"，美术写"长什么样"。

详细工作方式见 [策划agent原始修改区/agent.md](策划agent原始修改区/agent.md)。
