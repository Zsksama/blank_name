# 待派 · 出怪逻辑 T-501—T-504

> **给谁**：田
> **依据**：`10-战斗/37-M14出怪逻辑.md`（§七—§十三）
> **占位数值**：`数值设计组/待设计清单.md`
> **流程**：11-27 已与主策划逐条核对确认

**总原则**：**关卡开局就把这一关的敌人列表算好，之后只是按节奏放出来。**
总数是"钱买出来的"，不是预设的。

---

## T-501 敌人列表生成

**目标**：关卡开局一次性算好这一关出哪些敌人、各多少只。

**规则**

1. 读关卡配置（预算 / 难度倍率 / 允许池 / 必出）
2. `money = budget × difficulty_mult`
3. **先放必出项——不扣钱**（白送）
4. 循环：从允许池随机抽一个类型 → `cost ≤ money` 就加入列表并扣钱，否则重抽
5. 直到 `money < 最便宜的费用`
6. 列表只数 = `enemy_total` —— **这就是气焰的分母**

**边界**

- 必出项与随机项**分开记**，方便调试与日志
- 允许池只有一种类型时，列表就是清一色
- 生成要打**日志**：预算、只数、构成
- 支持**随机种子**，同种子可复现；**验收时固定一个种子**，正式版随机

**验收**

- [ ] 同一个种子，生成结果可复现
- [ ] 只数 ≈ 预算 ÷ 平均费用
- [ ] 必出项一定在列表里，且没扣钱
- [ ] 难度倍率提高 → 只数变多、构成比例不变

**依赖**：U-03（敌人费用）

## T-502 批次出怪

**目标**：按节奏把列表里的敌人放出来。

**规则**

1. 每 **6—10 s 随机**开一批
2. 每批 **1—5 只**，从列表里随机取（取走即移除）
3. **前 20%（按只数）优先出低费敌人**
4. **同屏上限 15**
5. 列表取空 → **停止出怪**

**边界**

- 同屏满了就**跳过这批**，不排队
- **接舷 / 暂停期间不出怪**
- 列表空且场上清空 → 全灭 → 胜利

**验收**

- [ ] 节奏稳定，不会忽快忽慢
- [ ] 同屏不超 15
- [ ] 开局前几只都是便宜船
- [ ] 接舷时不再刷怪

**依赖**：T-501

---

## T-503 阵型

**目标**：让某些批次按有出处的队形出现。

**规则**

1. 关卡配了 `formation_pool` 时，每批有 **40%**（占位）概率用阵型
2. **长蛇阵**：同一航道首尾相接出 2—3 只；
   **队首队尾挑贵的（强的）**，中间挑便宜的
3. **蝴蝶阵**：各道各 1 只（最多 5 只），**同时出现**
4. 阵型批次从列表里取对应数量

**边界**

- 列表数量不够时，**降级成普通批次**
- 同一航道同时不超过 2 只
- ❌ 不要做成整齐方阵——倭寇是"乌合之众"

**验收**

- [ ] 长蛇能看出"头尾强、中间弱"
- [ ] 蝴蝶是散开的、同时出现
- [ ] 没配阵型的关卡不出现阵型
- [ ] 列表不够时能安全降级

**依赖**：T-501 / T-502

---

## T-504 海螺与暂停交互

**目标**：每批一声海螺；出怪不与接舷打架。

**规则**

1. **每批一声**海螺，在批次生成、敌人未进场时
2. 音效：`音效音乐/enemy_spawn.wav`
   - ⚠️ 实测是 **Ogg Vorbis** 格式，只是扩展名写成 .wav；建议改名 `.ogg`
3. 接舷 / 暂停期间**停止出怪**，恢复后继续

**边界**

- 音效文件缺失时**静默降级**，不许报错崩溃

**验收**

- [ ] 一批一声，不是每只一声
- [ ] 接舷期间没有新敌人出现
- [ ] 音效失败不影响出怪

**依赖**：T-502

## 建议顺序

1. **T-501**（列表生成，地基）
2. **T-502**（批次出怪）
3. **T-503**（阵型）
4. **T-504**（音效与交互，最轻）

## 回传要求

1. 一关的**生成日志**（预算、只数、构成）
2. 一段出怪节奏的录屏（含海螺音）
3. 长蛇 / 蝴蝶各一次的画面截图
4. 接舷期间不刷怪的证明（日志或录屏）
