## 目标

把接舷战版本验收发现的问题修掉，并补两条显示。

## 规则

### ① 复活机制丢失（P0，先修）

- **现象**：第一次死亡后**没有触发复活**，后续又正常了。不稳定复现。
- **期望**：船沉没后按既有流程复活，**每次都稳定**；复活从水门驶出。
- **要求**：连续死两三次，每次都记录日志（死亡时间、复活时间、位置）。

### ② 接舷中显示双方舰体血量（P0，先修）

- **现象**：接舷过程中看不到双方还剩多少。
- **期望**：接舷界面显示**我方 / 敌方两条舰体血条**（只显示舰体即可，部位血条可以不显示）。
- 位置由程序定，别挡住中央的两条船。

### ③ 长按 T 撤退时长：1.5 s → **1.0 s**

- 其余逃跑参数不变（后退 200 px、各部位 −15%、气焰 +10）

### ④ 接舷伤害偏低

- **现象**：结束得太快（主策划："伤害可以调低一些，现在感觉结束的太快了"）
  注：原文如此——**结论是"拉长接舷时长"**，具体做法是把**输出系数调低**，让双方掉血变慢。
- **做法**：把 `每秒伤害` 的系数往下调（现在是 `对方战力 × 0.5`，先调到 **×0.3** 试）
- 具体数值后续交数值组，先做成可在检查器里调。

### ⑤ 镜头锁到地图外侧

- **现象**：撞击靠近地图边缘的敌人时，镜头居中会锁到地图外。
- **期望**：**相机位置夹在地图边界内**；夹住之后两船可以不居中，但画面里不能出现空白地图外区域。
- 备选（更贵）：复制地图背景。**先做夹边界**。

### ⑥ 灯火系数：改回三档

- 现在做的是四档 `1.2 / 1.0 / 0.8 / 0.6`
- 正确是**三档**：**渺茫 0.9 ／ 温和 1.0 ／ 明亮 1.1**
- 气焰四档系数保持不变（1.2 / 0.9 / 0.75 / 1.3）

## 边界

- ①②③ 是本轮必修；④⑤⑥ 可以本轮一起，也可以下一轮
- 不要动已经验收通过的部分（触发去重、撞击公式、QTE 边沿检测、时间恢复）

## 验收

- [ ] 连续死 3 次，每次都能正常复活
- [ ] 接舷时能看到双方舰体血条
- [ ] 长按 T 1.0 s 能撤退
- [ ] 一次接舷持续约 6—10 s（比现在明显变长）
- [ ] 贴着地图边缘接舷，画面里不出现地图外
- [ ] 灯火只影响三档系数（0.9 / 1.0 / 1.1）
