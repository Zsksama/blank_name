## T-301 堡实体：血条、宽度、四档外观

**目标**：堡是一条血的实体，宽度减半，随血量换四档外观，顶部显示等级与破损度。

**规则**

1. `fort_max_hp = 400`（保留）；**三档难度堡血相同**，难度只改出怪量与敌人强度
2. 横向占位 **120 px → 60 px**（贴图同比缩放）
3. **四档**（船的部位是三档，堡多一档"门没了"）：

   | 血量比例 | 档 | 表现 |
   | --- | --- | --- |
   | 1.0—0.6 | 完整 | 雉堞齐整、水门完好 |
   | 0.6—0.25 | 破损 | 墙皮崩落、雉堞缺角、冒烟 |
   | 0.25—0 | 破坏 | 墙体破口、水门半塌、火光 |
   | 0 | **门没了** | 水门洞开，敌人涌入 |

4. 阈值 **0.6 / 0.25**（**不用**船那套 0.75/0.10）
5. **"门没了"那张图在血归零的瞬间就切**，不等演出结束
6. 顶部 HUD：`堡Ⅰ/Ⅱ/Ⅲ` + 破损度百分比 + 炮位格

**边界**

- 堡**没有部位**：帆/舵/撞角/传导一律不套用
- 堡不参与接舷战
- 没有美术素材时，四档先用 tint/明度占位，**留 4 个贴图槽**

**验收**

- [ ] 堡宽约现在的一半，不挡最上面那条道
- [ ] 0.6 与 0.25 两个点换档，不会在阈值附近来回抖
- [ ] 0 时出现"门没了"那张图
- [ ] HUD 有等级、百分比、炮位格

**依赖**：无。

## T-302 炮位、射程（删除 blind_lane）

**目标**：炮按航道布；有炮的道才会开火；开局 4 门，水门道 0 门。

**规则**

1. **删除 `blind_lane` 变量**——不再有"盲道"设定
2. 开火判断只有一条：**该道有炮 ＋ 该道有敌船**
3. 开局炮位：道 0 / 1 / 3 / 4 各 1 门；**道 2（水门道）0 门**
4. 升级后水门道可补 1 门（上限 1 门/道；其余道上限 2 门；总数上限 6）
5. `turret_range = 360 → 400`
6. **不做任何提示**：没有虚线、没有色块、没有"盲道打不到"的文字

**边界**

- 炮位固定朝向，不旋转
- 水门道有没有炮，完全由炮位决定，不要用标志位控制

**验收**

- [ ] 中间道（水门道）没有炮，也不开火
- [ ] 其余四条道各一门炮，都会开火
- [ ] 画面里没有任何"盲道"提示
- [ ] 模板敌船停在 320 时，堡能打到它，它也能打到堡

**依赖**：战斗场景分道改造（`sea_top=144`、5 条道）。

## T-303 自动开火与目标选择

**目标**：本道有敌船就自动打，打最靠左的那艘。

**规则**

1. 只打**本道**敌人（`lane_index` 相同）
2. 目标 = 本道**最靠左（最接近堡）**的敌船
3. 各门炮独立冷却（`turret_cooldown = 3 s`）
4. **不消耗弹药**
5. **不误伤玩家船**
6. 弹道直射；命中判定沿用 M4

**边界**

- 多道同时开打时各炮互不支援
- 目标被击沉后立刻切下一个，不可对同一艘重复结算

**验收**

- [ ] 玩家船在堡前面时，堡不会打到玩家船
- [ ] 同道两艘敌船，先打靠堡的那艘
- [ ] 水门道有敌船时，堡不开火

**依赖**：T-302。

## T-304 受击与掉灯火

**目标**：敌人打堡掉血；按档掉灯火；战斗中堡不自愈。

**规则**

1. 敌人到 `stop_distance = 320` 停船，持续开火（E-01：8 伤 / 3 s）
2. **掉灯火按档**：

   | 堡血跌破 | 灯火 |
   | --- | --- |
   | 0.6 | −8 |
   | 0.25 | −12 |
   | 0 | −25 |

3. **重置粒度 = 每场战斗**：一场内各档只触发一次；下一场重新计
   （依据：战斗中堡不修，经营修好后再打就是新的一场）
4. 战斗中**不自动修复**；经营后修到 70%（接口留好，UI 本期不做）
5. 接口：`on_fort_damaged_tier(tier)`，接 `14-资源与灯火体系`

**边界**

- 同场回血再掉回同一档，**不重复触发**
- 灯火不能扣成负数

**验收**

- [ ] 跌破 0.6 时灯火 −8，同场只一次
- [ ] 跌破 0.25 再 −12
- [ ] 下一场战斗重新计数
- [ ] 战斗中堡不会自己回血

**依赖**：T-301；`14` 号灯火接口。

## T-305 破堡演出与判负

**目标**：堡血归零 → 最近的敌船驶入水门 → 本场失败 → 扣兜底 → 归零进结局。

**规则**

1. 堡血 ≡ 0 即刻停火，不再受击
2. 演出：取**离水门最近的那一艘敌船**，驶向水门 → 走上岸 → 走进门里 → 结束
3. 动画结束 → 本场战斗失败
4. 兜底次数：简单 3 / 普通 2 / 困难 1
   - 还有次数 → 消耗一次 →「乡兵击退了倭寇」→ 重整，下一场继续
   - 归零 → 进结局（内容本期不做，先打日志 + 留接口）
5. **演出期间立刻冻结玩家操作**：不能移动、不能开火、不能换道，只看演出
6. **「门没了」贴图在血归零那一瞬间就切**，敌船走过的是已经"门洞开"的那张图
7. 不做长时间慢镜头

**边界**

- 水门没有独立血量，堡血归零就是水门被破
- 船沉不算失败（扣灯火 + 重整）

**验收**

- [ ] 归零后，最近那艘敌船走向水门并进入
- [ ] 演出结束弹失败结算
- [ ] 兜底次数正确扣减；归零进入结局分支

**依赖**：T-301、T-304。

## T-306 警报文案与望楼接口

**目标**：堡挨打时按场景出一句明代文案，不烦人；望楼只留接口。

**规则**

1. 五句（出处见 `33` 号 7.3）：

   | 场景 | 文案 |
   | --- | --- |
   | 敌船靠近 | 贼船出没 |
   | 开始稳定攻击 | 贼攻城 |
   | 破损过半 | 台已半圮 |
   | 被攻破 | 城陷矣 |
   | 援兵到来（预留） | 义兵来集 |

2. 触发：敌人靠近并开始稳定输出之后才显示
3. 同一条提醒有冷却；多道同时开打**合并成一条**
4. 望楼：只加 `is_marked: bool` 与渲染钩子，**不实现效果**

**边界**

- 不许出现"鸣金""狼烟""礼炮"
- 文案不循环刷屏

**验收**

- [ ] 敌人停船开打后才出「贼攻城」，且只出一次
- [ ] 两道同时挨打只出一条提醒
- [ ] 代码里有 `is_marked`，但无任何加成

**依赖**：T-304。
