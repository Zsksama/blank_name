# 三、8 条拍板（我的建议，可直接勾）

| # | 问题 | 建议 |
| --- | --- | --- |
| 1 | k 值 | **0.05 保留**；文档补一句"正面高速撞 = 舰体 5%—10%" |
| 2 | 撞角损耗 | **按比例**（最大耐久 20%，单次上限 30%） |
| 3 | 气焰四档映射 | ⚠️ **程序写错了**：他写 ≥75 →1.2 / ≥25 →0.9 / ≥−25 →0.75 / 更低 →1.3，用的是 0—100 且会出现负数。正确是 **>0.85 嚣张 1.2 ／ 0.30—0.85 锐挫 0.9 ／ 0.10—0.30 弩末 0.75 ／ <0.10 穷寇 1.3**。1.3 是"崩溃反扑"，理解正确 |
| 4 | 侧面蹭 / 正面撞 | **认可**，写进 35 号 |
| 5 | 轻碰是否仍进接舷 | **仍进**——敌船贴上来本来就是低速接触，不进的话"被动接舷"永远触发不了 |
| 6 | 逃跑后退被海界夹住 | **允许夹住**：后退距离取 `min(200, 到边界距离)`，不报错、不做特殊处理 |
| 7 | 接舷期间堡血条 | **隐藏**（原设计就是隐藏部分 UI）；等气焰条做出来，气焰条保留 |
| 8 | 快照用途 | **保留**，注明"预留：战后结算/修复"，现在只写日志没问题 |

# 五、验收动作（主策划实操清单）

打开整合版，走一遍：

- [ ] 贴着敌船 → 能进接舷
- [ ] 接舷中再贴 → 不重复触发
- [ ] 结束 3 s 内贴 → 不触发
- [ ] **不同道的两船 X 对齐** → 不该触发（这是程序修掉的那个 bug）
- [ ] 换道途中撞上敌船 → 等落位才结算
- [ ] 撞角完好 vs 破损，撞一下掉血明显不同
- [ ] 接舷中空格连点 → 倍率上升；停手 → 回落
- [ ] 长按 T 1.5 s → 逃跑（后退、各部位掉血）
- [ ] 打赢 → 敌船沉、镜头复位、UI 恢复
- [ ] 连续两次接舷 → 无残留

**十项全过 = 这一版验收通过。**
