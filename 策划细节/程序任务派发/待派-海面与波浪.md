**总原则**

2. **美术没到的部分先占位**：天空与海面底图等美术，水线与浪花程序自己出

## T-601 水线

**目标**：5 条航道各有一条会起伏的水线。

**规则**
1. 每条道一条水线，横贯海域
2. **浪的形态由程序定夺**（要自然、不呆板，怎么叠由程序决定）
3. 五条水线的**相位错开**——肉眼不能同步
4. **远近差异**：越远的道，浪越小、越淡、越慢（比例按文档试，效果不好自行调整）
5. 最上面那条是**地平线**：**做轻微起伏**（幅度远小于航道水线），颜色最淡
6. 采样密度按性能定

**边界**
- 只改视觉；**逻辑用的 y 一律不变**
- 不影响命中、AI、碰撞

**验收**
- [ ] 五道浪肉眼不同步
- [ ] 远道平、近道大，有纵深感
- [ ] 单独隐藏地平线，画面几乎无变化
- [ ] 开/关浪，打靶命中率一致

**依赖**：分道几何（`sea_top = 144`、5 道、6 条线）

## T-602 浪花

**目标**：水线上有看得见的浪花。

> 美术已交付 **3 张浪花图**（约 175×42 / 184×42 / 169×52），**没有做无缝**，所以**不铺满**。

**规则**
1. **沿水线撒点**，不做连续平铺
2. 撒点规则：间距随机、**三张随机取一**、**随机水平翻转**
3. 越远的道**越小、越淡**
4. 水线本身仍是一条亮线（程序画），浪花是贴在上面的装饰
5. 夜间 / 暴雨用**颜色 tint**，不另出素材
6. 程序自己生成的浪花**作为兜底**，只在素材缺失时启用

**边界**
- 不能出现"一眼看出是同一张在重复"的排列
- 浪花不能盖住船体
- 用 **PNG** 原图，不用 webp

**验收**
- [ ] 看不出明显的重复图案
- [ ] 三条以上的道同时看，浪花不打架
- [ ] 近道大、远道小，有纵深
- [ ] 夜间染色后不发脏

**依赖**：T-601

## T-603 遮挡层与船随浪

**目标**：水线以下遮住船底；船随浪升降、轻微倾斜。

**规则**
1. 水线以下用**与水面同色的区域**遮住船底
2. 这一层要画在**本道的船与炮弹之后**
3. 船随浪：读**船头、船尾**两点水面高度 → 平均定升降、差定倾斜
4. 只动船的视觉；**碰撞箱、弹道起点、AI 不动**
5. **炮口暂时不跟浪走**

**边界**
- 倾斜有上限，不能让船看起来要翻
- 换道过程中也要正常跟随

**验收**
- [ ] 船底浸水部分被水色盖住
- [ ] 船起伏自然、倾斜看得出来但不过分
- [ ] 开炮的起点不随浪变化
- [ ] 打中判定与浪无关

**依赖**：T-601

---

## T-604 局部扰动

**目标**：船经过时浪变小；炮弹入水起波纹。

**规则**
1. **船压浪**：船附近的浪幅平滑降低
2. **炮弹入水**：落点两侧叠加一个会衰减的波
3. 两者都通过"改对应那一段水线高度"实现

**边界**
- 多个扰动叠加时**要限幅**，不能越叠越夸张
- 不改变任何逻辑

**验收**
- [ ] 船经过处浪明显变小，离开后恢复
- [ ] 炮弹入水看得见波纹
- [ ] 连续打十发，水面不失控

**依赖**：T-601

---

## T-605 倒影与碎片落水

**目标**：所有船与炮弹有倒影；受击碎片落水溅起水花。

> 尾流已移到「后续更新」，本卡不含。

**规则**
1. **倒影**：垂直镜像、低透明度、方向相反地跟着倾斜
   - **玩家船 + 全部敌船 + 所有炮弹**（箭矢除外）
   - 倒影必须**被遮挡层裁掉**，不能越过水面以下的范围
2. **碎片**：船被击中掉粒子（木屑/帆布/铁屑），走抛物线，**触到水线生成小水花**

**边界**
- 倒影要能**一键整体关闭**（同屏船多时保性能）
- 粒子数量要可控，long 时间运行不能越积越多

**验收**
- [ ] 玩家船、敌船、炮弹都有倒影
- [ ] 倒影不出界、不悬空
- [ ] 碎片落水能看到小水花
- [ ] 关掉倒影后帧率回升
- [ ] 连续战斗 30 s，粒子数量稳定

**依赖**：T-603

## T-606 时间同步与暴雨

**目标**：接舷/暂停时浪跟着慢或停；暴雨时浪更大。

**规则**
1. 浪的推进**用同一个 delta**（受 `time_scale` 影响）
2. 接舷 `time_scale = 0.03` → 浪几乎静止
3. **真暂停 → 完全冻结**
4. 暴雨：浪幅 × 倍数、速度 × 倍数
5. 接舷时是否**淡出浪**做成开关，先看效果

**边界**
- 接舷**演出层**（UI、镜头）仍用真实时间，不受影响
- 暴雨只改浪，不改视野、不改船速

**验收**
- [ ] 接舷时浪明显慢下来
- [ ] 暂停时浪完全不动
- [ ] 暴雨关浪明显更大
- [ ] 接舷的 UI 动画速度正常

**依赖**：T-601、M8 接舷

## 建议顺序

1. **T-601** 水线（地基）
2. **T-602** 浪花（有它才看得出是浪）
3. **T-603** 遮挡与船随浪（这条做完效果就出来了）
4. **T-604** 扰动
5. **T-605** 倒影与碎片
6. **T-606** 时间与天气（收口）

## 回传要求

1. 静止画面：五道浪不同步 + 远近平滑
2. 录屏：船开炮时随浪起伏、船底被遮、炮弹有倒影
3. 接舷时的一帧：浪几乎静止
4. 开/关水的帧率对比
