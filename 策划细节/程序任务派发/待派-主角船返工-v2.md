## T-112 画面分层与海平面（最优先）

**目标**：把战斗画面改成"上面 144 px 是天空和 UI，下面 576 px 切成 5 条海道"，并且每条道是一组独立的层。

**规则**

1. 几何（直接改数）：
   ```
   sea_top = 144.0
   sea_bottom = 720.0
   lane_count = 5
   lane_height = 115.2
   ```
2. **6 条海平面**（从远到近）：`144 / 259.2 / 374.4 / 489.6 / 604.8 / 720`
   - 第 i 条道的船骑在**第 i+1 条**线上（现有 `lane_bottom_y()` 保留）
3. **删除"整块大海"**：`battle.tscn` 里那个 `Sea` Sprite2D 不再整片盖住背景
4. 每道一组，从远到近叠：
   ```
   海平面线 → 本道内容（船 / 炮弹 / 水花） → 本道水体带
   ```
5. z_index：第 i 组 = 线 `10+i*4`、内容 `11+i*4`、水体 `12+i*4`；Land 50；准星 60；HUD 不变
6. **船的 z_index 随所在航道动态变化**，换道时重算
7. 水体带**只画本道那 115.2 px**，透明度用 `water_alpha`（起始 0.85）

**边界**

- 最上面那条线以上的区域**不是航道**，不参与分道计算
- 水体带**绝不允许跨道**（不能整屏一块色）
- 炮弹落在本道水面以下 → 被本道水体盖住；飞高越过上方道 → 可见；**不得出现在下方道**
- 隐藏任意一条海平面，**上方背景不能有任何变化**

**验收**

- [ ] 画面最上方能看见天空，`Y<144` 区域内没有海道线
- [ ] 从 `Y=144` 往下数一共 **6 条**线，最后一条贴着窗口底边
- [ ] 开炮后船体部分没入水色，约 1 s 回来
- [ ] 把炮弹打进第 2 条道的水里：水花在线上面炸开，**炮弹本体消失**，第 3 条道不出现它
- [ ] 隐藏任意一条线，上方背景不变

**依赖**：无。做完再做 T-118（水花）里的验收项。

## T-113 船体尺寸与炮管锚点

**目标**：船缩到当前的 1/4（约 **70—76 px 宽**），炮管不再悬空。

**规则**

1. 船体（含 Sprite、三部件箱、帆/船体 overlay）**同比缩放到 1/4**
2. `muzzle_offset` **不再写死 (48,0)**，改为从 `CannonBox` 与当前船体尺寸推导
3. 炮台挂点、炮管贴图、炮口位置三者**共用一套尺寸来源**，改船大小只需要改一处

**边界**

- 缩放后三部件箱必须仍然盖住画面上对应的部位（帆/舰体/火器与弓手）
- 船宽不得超过水门净宽（4.2 m 对应的像素上限，见 `33` 号 S-10）

**验收**

- [ ] 炮管根部**接在船身上**，不再悬空
- [ ] 部件箱与美术图对得上（打帆掉帆、打火器与弓手掉炮台）
- [ ] 开炮时炮弹从炮口出，不从船心出

**依赖**：T-115（后坐力起点要用炮口位置）。

## T-114 移速与换道锁定

**目标**：船慢下来；换道那零点几秒内不能动、不能开炮。

**规则**

1. `move_speed = 25`（当前 250）
2. 换道动画期间：**左右移动无效、开火无效**
3. 动画结束**立刻解锁**，不做额外延迟

**边界**

- 换道动画期间**炮口仍可跟随鼠标转**，只是不能开火
- 连续按 W/S 不叠加多层动画

**验收**

- [ ] 横向移动明显变慢（横穿约 1000 px 要 ~40 s）
- [ ] 换道动画中按 A/D 不动、按左键不开炮
- [ ] 动画一结束，立刻能走能打

**依赖**：无。

## T-115 后坐力

**目标**：开火有真实的**后退位移**，1 s 内缓慢回来，带惯性与浮力感。

**规则**

1. 开火瞬间：`global_position.x` 沿炮口反方向**真实位移**（不是只偏移子节点）
2. 回复时间 `recoil_recover_time = 1.0`（当前 0.18）
3. 回复曲线用 **ease-out**（先快后慢），可调
4. 下沉写入 `lane_offset_y`，**绝不改 `lane_index`**
5. 位移量、下沉量、翘头角度都保留为 `@export`

**边界**

- 后退**不能把船推进城墙**（撞墙就停在墙边）
- 连续开火可叠加，但要夹一个上限
- 下沉后船体可能被本道水体盖住 —— 这是**期望效果**，不是 bug

**验收**

- [ ] 开一炮能看到船明显后退，然后约 1 s 慢慢回位
- [ ] 后退期间再开一炮，炮口起点跟着变了（不是原地出弹）
- [ ] 船不会退进左侧城墙里
- [ ] 下沉时船体被水色盖住一部分

**依赖**：T-112（水体层）、T-113（炮口锚点）。

## T-116 弹速与射程

**目标**：炮弹慢下来，不再一眨眼飞出屏幕。

**规则**

1. `shell_speed = [520, 680, 420]`（当前 `[1050, 1150, 820]`，这是 24 号定值的两倍）
2. `gravity = 900` 保留，`drag_k = 0` 保留
3. 预瞄线与实弹继续共用同一套积分器

**边界**

- 改完弹速后，预瞄线必须自动跟着变（不许两套参数）

**验收**

- [ ] 三种弹的飞行速度肉眼可分辨（破帆最快、爆炸最慢）
- [ ] 能完整看见炮弹的抛物线弧线
- [ ] 预瞄线与实际落点一致

**依赖**：无。

## T-117 堡宽、盲道与炮门数

**目标**：堡变窄，盲道挪到中间的水门道，炮门改成 4 起步。

**规则**

1. 堡的横向占位 **120 px → 60 px**
2. `blind_lane = 2`（当前 0 = 天空那条，错的）
3. 开局炮门 **4 门**，分布在道 0 / 1 / 3 / 4，各 1 门
4. 水门道（道 2）炮位上限 **1 门**，开局 0 门
5. 总上限 **6 门**（首版）

**边界**

- 盲道在画面上仍然用**虚线**提示（`show_blind_lane_hint` 保留）
- 堡变窄后不能盖住道 0 的航道

**验收**

- [ ] 中间道没有炮，且有虚线提示
- [ ] 其余四条道各有一门炮
- [ ] 堡的宽度约为现在的一半

**依赖**：T-112（分道几何）。

## T-118 接舷提示（只留接口）

**目标**：船靠近敌船时，终端打印一行字；接舷战本身不做。

**规则**

1. 触发：**同一条道**、水平距离 < 60 px
2. 打印内容建议：`[接舷] <敌船名> 逼近，接舷战未实现`
3. 冷却：1 s，不要每帧刷屏

**边界**

- 只打印，**不改变任何战斗数值**
- 离开距离后不再打印

**验收**

- [ ] 贴上去能看见一行提示
- [ ] 不刷屏
- [ ] 血量、位置、速度都不受影响

**依赖**：无。

1. **T-112**（地基，后面全依赖它）
