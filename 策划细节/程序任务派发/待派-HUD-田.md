把现在挤在顶部两行文字的临时 HUD，换成**分区版 HUD**：左上弹药与部位、顶部灯火、右上关卡与敌数、左堡右气焰、左下操作环。

## 规则

### 1. 版面（1280×720 基准）

| 区域 | 放什么 |
| --- | --- |
| 左上 | 暂停键（三条竖线，点击→屏幕变灰）；弹药三胶囊**带数量**；五部位**小圆圈** |
| 顶部中央 | **灯火大圆环**；下方 `沉敌数：xxx` |
| 右上 | 关卡名；`敌人 11 / 19`（分母=**名单总数**） |
| 左侧竖条 | 堡血条 + 百分比（**不显示炮位**） |
| 右侧竖条 | 气焰条 |
| 左下 | 装填冷却圆环（分两段、剩余秒数写在环上）+ 中间三块弹药选择 + 右侧齐射/单射 |
| 底部居中 | 操作提示行，半透明，鼠标悬停变不透明 |

### 2. 部位圈的形态（重点）

- **环形填充**，填充**细**（2—3 px）
- 颜色 = 状态：**绿（完好）/ 黄（破损）/ 红（破坏）**，阈值 75% / 10%
- **悬停**显示名称 + 百分比
- 顺序默认 **帆 / 舰体 / 火器与弓手 / 舵 / 撞角**（与代码数组一致）

### 3. 弹药的形态

- 左上：三个胶囊显示**剩余数量**
- 左下：圆环中间切三块做**选择**，当前高亮
- 数量为 0 时框变灰；**再点击 → 闪烁 + 音效 + 一句台词**

### 4. 齐射 / 单射

- 圆环右侧两个框，当前高亮
- **切换时发光框左右滑动**

### 5. 接舷收缩

- 弹药、部位圈、装填环、齐射框**整体上移**
- **灯火不动**

### 6. 缩放

- 1280×720 基准，按锚点缩放；大窗口（如 2544×1422）不得错位

### 7. 顺手补的一件

- **常规战斗要有伤害飘字**（现在只有接舷有）：打中船身飘 `-12`

## 边界

- **不改战斗逻辑**，只做表现层
- **不重画贴图**：本轮只定位置与形态，美化后续
- 下列**本轮不做**（已在 `44` §五 登记）：气焰四档刻度、余败场图标、胜负提示、暂停菜单、维修提示、掉灯火跳字、波次预警、望楼目标小血条、沉敌数火焰特效
- 暂停只做"屏幕变灰"，不做菜单
