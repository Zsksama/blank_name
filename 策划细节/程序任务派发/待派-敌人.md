# 二、共享规则摘录（田做敌人必须遵守的部分）

## 2.1 航道

- 每条船（玩家、敌人、炮弹）都有 `lane_index`（int）
- 航道是**逻辑概念**，Y 轴不连续；`lane_offset_y` 只用于视觉起伏/后坐，**不改 `lane_index`**

## 2.2 跨道过滤（重要）

- 炮弹命中判定前先比 `lane_index`
- **不同道 → 直接穿过**：不结算、不消失、不减速
- 敌人目标选择也受此限制：**不同航道永远不打玩家**

## 2.3 碰撞箱与穿透

| 部位 | 碰撞箱 | 行为 |
| --- | --- | --- |
| 帆 | 软 | 炮弹穿透，继续飞 |
| 舰体 | 硬 | 弹药销毁 |
| 炮台 | 硬 | 弹药销毁，并对舰体追加伴随伤害 |
| 舵 / 撞角 | 无 | 只能靠传导受伤 |

- 同一发炮弹对同一部位**只结算一次**（用 `hit_parts` 集合）

## 2.4 三档阈值与 debuff（敌我通用）

- 状态由 `hp / hp_max` 实时算：`≤0.10` 被破坏、`≤0.75` 破损、否则正常
- debuff 直接改参数：

| 部位状态 | 效果 |
| --- | --- |
| 帆 破损 / 被破坏 | 速度 ×0.7 / ×0.4 |
| 炮台 破损 / 被破坏 | 攻击间隔 ×1.3 / **无法开火** |
| 舵 破损 / 被破坏 | 换道耗时 ×1.4 / 无法换道 |
| 撞角 破损 / 被破坏 | 撞击 ×0.5 / 无法撞击 |

- **行为树不判断部位**，只读 `speed`、`attack_cd` 的最终值

## 2.5 弹道

- 与玩家同一套积分器：`a = -drag_k·|v|·v + g`，固定 dt
- 敌人开火用固定初速，**不做提前量预判**
- 射程由初速与角度自然决定

## 2.6 后坐力（敌人也要）

- 水平后移 + 竖直下沉，**只做视觉**
- 下沉写入 `lane_offset_y`，**绝不改 `lane_index`**

# 三、任务卡

## T-201 敌船数据模板

**目标**：用数据文件配置出一种敌人，代码里没有针对 E-01 的特判。

**规则**
- 模板字段见 `28-敌人模板.md`：`id`、`display_name`、`sprite`、`size`、`parts`、`speed`、`stop_distance`、`min_gap`、`attack_*`、`can_change_lane` 等
- `parts` 用**二维数组**，每行 `[部位ID, 当前血量, 上限, [实心倍率, 破帆倍率, 爆炸倍率], 碰撞箱软硬, 状态]`
- 传导表用二维数组：行＝主命中（帆/舰体/火器与弓手），列＝目标（舵/撞角），值＝`[概率, 比例]`
- 数据结构的具体实现由程序定，只要语义对得上

**边界**
- 字段缺失要有默认值，不能崩
- 倍率数组长度必须为 3，长度不对要报错而不是静默

**验收**
- [ ] 改数据文件里的 `speed`，不重启不改代码即生效
- [ ] 同一个模板能配出第二种敌人（只改数）

**依赖**：无

---

## T-202 敌船生成与航道占位

**目标**：敌人能按配置出现在指定航道，且同航道不重叠。

**规则**
- 生成时指定 `lane_index` 与 `spawn_x`（屏幕右侧外）
- 同航道内任意两船 x 距离 ≥ `min_gap`，否则生成延后
- 维护一个"航道占用"表供换道判定使用

**边界**
- 同一帧生成多艘时不能重叠
- 航道被堵满时，新船排队等待而不是叠在一起

**验收**
- [ ] 同航道连续生成 5 艘，肉眼看不到重叠
- [ ] 航道占用表能被换道逻辑读取

**依赖**：T-201

---

## T-203 移动与停位

**目标**：敌船沿航道向左推进，前方有同伙时减速跟随，到 `stop_distance` 停下。

**规则**
- 每帧：`x -= speed * dt`
- 若前方 `min_gap` 内有同伙 → 速度降到前车的 90% 或停下
- 距堡 ≤ `stop_distance` → 停止前进，进入输出状态

**边界**
- 减速不能变成"抖动"（要有个缓冲区间，不是硬停）
- 已经停在 stop_distance 的船被后车追尾时，后车必须停下

**验收**
- [ ] 前方有船时后车明显减速，不会穿模
- [ ] 到达 stop_distance 后不再前进

**依赖**：T-202

---

## T-204 行为树：目标选择

**目标**：按优先级决定每帧做什么：打玩家 → 打堡 → 前进 → 等待。

**规则**
（这是优先级选择，从上往下第一个满足的执行）

```
1. 舰体归零      → 沉没
2. 士气 ≤ 阈值    → 撤退（士气接口见 T-208）
3. 玩家同航道 且 距离 ≤ attack_range → 打玩家
4. 堡在 attack_range 内            → 打堡
5. 前方无同伙                      → 前进
6. 以上都不满足                    → 原地等待
```

- **不同航道永远不打玩家**
- 打堡时**停在原地持续输出**，不撞击
- 行为树只读参数，不判断部位状态

**边界**
- 玩家从射程边缘进出时，不能疯狂切换目标（加 0.3 s 冷却）
- 目标丢失（玩家沉没/换道）要能立刻重选

**验收**
- [ ] 玩家同道进入射程 → 立刻转火玩家，不再打堡
- [ ] 玩家换到别的道 → 立刻切回打堡
- [ ] 射程外 → 继续前进，不开火

**依赖**：T-203

---

## T-205 敌方开火

**目标**：进入射程后按间隔自动开火，弹道与玩家一致。

**规则**
- 自动瞄准目标（朝向即可，不做鼠标跟随）
- 每 `attack_interval` 秒发一发，受装填冷却限制
- 弹道用共享积分器；初速固定
- 弹药无限，只受间隔限制

**边界**
- 炮台被破坏 → **完全不能开火**（见 2.4）
- 目标在射程边界时不要连续开火又取消

**验收**
- [ ] 开火间隔与配置一致
- [ ] 炮台被破坏后再也不开火
- [ ] 敌方炮弹与玩家炮弹走同一套积分器（可视对比弹道形状）

**依赖**：T-204、共享弹道实现

---

## T-206 敌方受击：碰撞箱与部位

**目标**：玩家炮弹能正确命中敌船部位，规则与玩家船一致。

**规则**
- 三个 `Area2D`：帆（软）、舰体（硬）、火器与弓手（硬）
- 命中前先比 `lane_index`
- 帆穿透（不销毁，继续飞）、舰体/火器与弓手销毁并停
- 火器与弓手命中 → 对舰体追加伴随伤害（系数配置）
- 同一发对同一部位只结算一次
- 血量变化后实时更新状态与 debuff

**边界**
- 跨道炮弹不得触发任何结算
- 同一帧内多个碰撞箱重叠时，只结算最先接触的那个（按穿透规则）

**验收**
- [ ] 打帆后炮弹继续飞，能再命中舰体
- [ ] 跨道飞过不触发伤害
- [ ] 部位跨 75% / 10% 时 debuff 立刻生效

**依赖**：T-201、共享碰撞实现

---

## T-207 敌方传导

**目标**：打舰体/火器与弓手时，舵与撞角按概率受伤。

**规则**
- 用传导二维表：舰体→舵 15%、舰体→撞角 10%、炮台→舵 10%、炮台→撞角 10%，伤害比例 30%
- 帆不传导
- 每发对每个传导目标最多一次

**验收**
- [ ] 反复打舰体，舵/撞角血量缓慢下降
- [ ] 打帆时舵/撞角完全不变
- [ ] 把概率改成 0，不再传导（不用改代码）

**依赖**：T-206

## T-211 换道接口（默认关闭）

**目标**：把换道规则写进去但不启用，后续敌人直接打开即可。

**规则**
- 字段：`can_change_lane`（默认 false）、`lane_change_margin`
- 规则：目标航道**有人 → 换道失败，原因记 `"有人"`**，进入冷却
- 何时触发换道：**未定**，先留一个空函数 `should_change_lane() → false`

**验收**
- [ ] `can_change_lane = false` 时行为完全不变
- [ ] 手动置 true 后，被挡时会记录 `lane_change_fail_reason = "有人"`

**依赖**：T-203
