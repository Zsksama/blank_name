# 待派 · 接舷战 T-401—T-406

> **给谁**：天羽
> **依据**：`10-战斗/35-M8接舷战.md`（11-25 定稿）、`37-M14出怪逻辑.md`（气焰）
> **占位数值**：`50-数据与单位/待设计清单.md` **N-17—N-37**
> **流程**：本套卡在 11-25 已与主策划逐条核对确认，可以直接派

**总原则**：接舷是**被动作战**，玩家随时可以主动撞，但**系统不给任何加成**——划不划算是玩家自己按公式算的账。

---

## T-401 触发与判定

**目标**：两船接触即进入接舷，且不会重复触发。

**规则**

1. 接触判定：**同航道** + 碰撞箱相交（或中心距 ≤ 40 px，占位）
2. 三种进入方式**走同一个入口**：敌船贴上来 / 玩家主动撞 / 换道重叠
3. 进入的**同一帧**结算一次撞击伤害（T-402）
4. 去重：同一对船 **3 s 冷却**；**接舷进行中不再触发**
5. 进入时记录双方快照（舰体血量、撞角耐久、战力）

**边界**

- **敌船之间重叠不触发接舷**，只有玩家船 × 敌船
- 已沉没的船不参与
- 接舷中玩家船沉 → 直接走失败

**验收**

- [ ] 贴着敌船能进入接舷
- [ ] 接舷中反复贴，不会重复触发
- [ ] 结束 3 s 内再贴，不触发
- [ ] 两艘敌船叠在一起，不触发

**依赖**：M1 移动、M12/M13 敌船

## T-402 撞击伤害

**目标**：进入接舷的瞬间，按公式结算一次撞击伤害。

**规则**

1. `伤害 = 相对速度 × (吨位Y / 吨位X) × 撞角减伤(X) × k`
2. `撞角减伤 = 撞角剩余耐久 × 0.7`；阈值复用 M4（0.75 / 0.10）
3. **双方各算一次**，各用自己的撞角
4. 撞角耐久损失 **0.2**（上限 0.3）
5. **换道重叠不走公式**，走**固定伤害 5**
   - ⚠️ 5 只是占位：**现在双方舰体血量还没定**，程序实现时把这个值做成可调参数，
     等数值组给了舰体血量再回头校一次
6. 撞完双方都没沉 → 进入接舷

**边界**

- **撞沉了就撞沉了**：撞击伤害直接把一方舰体打到 0，就不再进接舷，直接走击沉流程
- 相对速度低于 **80 px/s** 时算"轻碰"，撞击伤害按 0 处理（仍会进接舷）

**验收**

- [ ] 撞角完好 vs 撞角破损，同一速度下伤害明显不同
- [ ] 双方都掉血
- [ ] 撞完撞角耐久下降 0.2
- [ ] 换道重叠只掉固定 5，且该值可在编辑器里调

**依赖**：T-401

## T-403 接舷过程

**目标**：双方舰体持续掉血，直到一方归零。

**规则**

1. 进入即 `Engine.time_scale = 0.03`（占位）
2. `我方输出 = 我方战力 × 灯火系数 × qte_mult`
3. `敌方输出 = 敌方战力 × 气焰系数`
4. 每秒：`双方舰体 -= 对方输出`；`其余部位 -= 舰体伤害 × 30%`
5. **接舷自身计时用真实时间**，不跟 `time_scale`
6. 部位血量下限 0；**舰体归零即结束**

**边界**

- 接舷期间**不能开炮、不能换道**
- 其它敌船、碉堡炮火都被减速到 3%

**验收**

- [ ] 双方血量同步下降，能打出日志
- [ ] 灯火三档下速度不同
- [ ] 气焰四档系数各测一次（1.2 / 0.9 / 0.75 / 1.3）

**依赖**：T-401、M3/M4 部位

## T-404 QTE 与逃跑

**规则**

1. 进入接舷时**屏幕出现文字提示：按空格**
2. `qte_mult` 初始 **1.0**，范围 **[1.0, 1.5]**
3. 每按一次空格 **+0.01**
4. 每 **0.3 s** 自然 **−0.01**
5. **长按 T 1.5 s** → 逃跑

**边界**

- 逃跑**不中断**（没有"中途受伤则中断"这条）

**验收**

- [ ] 按住空格倍率上升，停手回落
- [ ] 倍率不超过 1.5
- [ ] 长按 T 触发逃跑

**依赖**：T-403

## T-405 三种结局与气焰

**规则**

| 结局 | 条件 | 结果 |
| --- | --- | --- |
| 胜利 | 敌方舰体归零 | 击沉敌船 + **气焰 −25** |
| 逃跑 | 长按 T 成功 | 后退 200 px、各部位 −15%、**气焰 +10** |
| 失败 | 我方舰体归零 | 走击沉流程：扣灯火、下场从水门再出 |

- 结束（任何结局）后敌船**僵直 0.5 s** 再恢复行为树
- 气焰变化走 M14 的管线（击沉另有 −0.5±0.1 立即扣 + 2 s 缓降）

**验收**

- [ ] 三种结局都能走到
- [ ] 气焰数值与显示同步

**依赖**：T-403、T-404、M14

## T-406 镜头、UI 与时间恢复

**规则**

1. 相机**缩放并居中两船**，过渡用**真实时间**
2. 进入时：隐藏**堡血条**等部分 UI；**气焰条保留**并加发光/颤抖（占位）
3. 撞击瞬间显示大字「**撞击！**」
4. 退出时按顺序：恢复 `time_scale` → 清空按键状态 → 恢复 UI → 解除去重冷却

**边界**

- 接舷期间**准星隐藏**
- 连续两次接舷不能有残留（相机、UI、时间倍率）

**验收**

- [ ] 进出两次接舷，状态完全干净
- [ ] 气焰条在接舷中仍然可见
- [ ] 相机会复位

**依赖**：T-401—T-405

## 建议顺序

1. **T-401**（触发与去重，最底层）
2. **T-402**（撞击伤害，可与 401 一起）
3. **T-403**（接舷过程与减速）
4. **T-404**（QTE 与逃跑）
5. **T-405**（结局与气焰）
6. **T-406**（镜头、UI、恢复——最后收口）
