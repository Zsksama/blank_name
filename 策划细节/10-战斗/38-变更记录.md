# 2026-11-26

## C-01 敌人炮台从舰体里挪到甲板上

| 项 | 内容 |
| --- | --- |
| **旧 / 当前版本** | 敌船的"炮台"在**舰体部位内部**，很难单独打到 |
| **新** | 炮台挪到**舰体上方、甲板位置、帆与舰体之间**，向外伸出，更醒目也更好打 |
| **理由** | 让"打火器与弓手"变成一个**看得见、打得到**的动作，而不是碰运气 |
| **史实** | **已考究：敌船上没有炮**。也就是说**"敌人的炮台"整个是我们的改编**，因此位置、表现怎么改都行，不受史料约束 |
| **攻击表现** | **已定：改成箭矢**。射程与伤害都**降低**；箭矢很小，**由程序生成，不专门画美术** |
| **重船特例** | 重船可配**火铳**——用炮弹素材**缩小**当子弹 |
| **影响** | M4 碰撞箱（三箱位置）、美术（敌船贴图）、命中判定、部位血条 |

## C-02 堡不再百分百命中

| 项 | 内容 |
| --- | --- |
| **旧** | 堡直射、无散布、**必中** |
| **新** | 快船机动灵活，**堡难以击中**；堡的**准度可调**；**射速不一定很低**，火力整体**较高** |
| **实现方式** | **快船持续反复左右移动**（会走位），堡因此打不中 |
| **理由** | 让"快船必须由玩家处理"这条分工成立 |
| **影响** | M15 开火规则；数值设计（准度、射速、火力）后续定 |

## C-03 望楼（M11）启用

| 项 | 内容 |
| --- | --- |
| **旧** | 只留 `is_marked` 接口，不生效 |
| **新** | 望楼**每 X 秒锁定一艘敌船**并使其**整船受到伤害提高**；只锁一艘，直到它死亡；锁**最快**的那艘 |
| **表现** | 准星（黄/红/不断变色）**旋转 + 放大缩小**地套在目标上 |
| **不是** | 不是"锁定部位加伤"，是**整船加伤**；也不针对部位 |
| **影响** | M15 / M11 / HUD |

## C-04 关卡：5 关，用日期命名

| 项 | 内容 |
| --- | --- |
| **旧** | 关卡数、命名方式都未定 |
| **新** | **5 关**：**2 白天 + 2 黑夜 + 1 黑夜暴雨**；关卡名**暂用日期**代替 |
| **影响** | M14 出怪、场景（暴雨）、美术（天气） |

## C-05 敌船分三类，各有角色

| 类型 | 特征 | 谁来处理 |
| --- | --- | --- |
| **快船** | 跑得快、**持续反复移动** | 堡打不中 → **玩家破帆** |
| **普通船** | 各项正常 | **玩家先破炮台** |
| **重船** | 移速慢、射程远、火力猛 | **堡来处理**；玩家的任务是**清掉它附近的杂船**，别让杂船吸走堡的火力 |

- 影响：M12/M13 敌船模板与行为、M15 堡的目标选择
