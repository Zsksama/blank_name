# 一、画面分层（定案）

美术交 **三张素材**，程序在运行时合成：

| 层 | 素材 | 内容 | 说明 |
| --- | --- | --- | --- |
| 1 | **白天天空** | 天空 + 云 + 远景小岛 | 基准版就是白天 |
| 2 | **海面底图** | 一整片**连续**的海 | 远处纹理细而淡，近处稍宽、稍清楚 |
| 3 | **透明浪边** | **2—3 段不同长度**的浅蓝浪纹 + 少量泡沫 | 排成能横向循环的透明贴图，段间留空 |
| 4 | **运行时水线** | 程序生成 | 每道一条连续水线，沿线平铺浪边贴图；**同时用来遮住船底浸入水中的部分** |

> **分工一句话**：贴图负责"浪看起来是什么样"，水线负责"浪怎么动"。
> 就算浪纹中间有空隙，水线也能连续遮住船底。

# 三、波浪怎么动

| 场景 | 做法 |
| --- | --- |
| 常态 | 每道水线有**轻微起伏**；五道共用素材，**错开图案位置与起伏节奏**，远道淡一点、近道清楚一点 |
| 船在道中 | **船身附近浪幅平滑变小**（船压住了浪） |
| 船的姿态 | **船头、船尾各读一个水面高度**：平均值决定升降，高度差决定倾斜方向 |
| 炮弹入水 | 在落点两侧叠加一道**逐渐衰减的波** |
| 巨浪（后续） | 依次改变经过的几道水线 |
| 碎片落水 | 独立生成密集小水花；同一批碎片可合用一次轻微扰动 |

# 四、性能（田给的估算）

| 项 | 数 |
| --- | --- |
| 采样密度 | 每 **16—24 px** 一个水线点 |
| 5 道合计 | 每帧约 **260—390 个点** |
| 判断 | **就波形计算而言是轻量的** |
| 真正开销 | 每帧反复创建浪花节点 + 大量透明粒子叠加 |
| 首版方案 | 每道**复用一条浪线 + 一块遮挡水面**；接入后用 Godot Profiler 对比开关水面时的帧耗时 |

# 八、田的派发单里可直接用的

| 项 | 内容 |
| --- | --- |
| 天空 | **地平线在 Y=144**；HUD 区保持低对比；云与远岛在源文件里单独留层 |
| 海面底图 | 连续一整片；把零散、低对比的碎光直接画进底图；**关掉浪边时它自己也要像一片海** |
| 浪边 | 2—3 种短浪边，透明底，只留**断续的浪脊亮边**和疏落泡沫；标同一条**平水基准**，方便程序沿水线摆 |
| 五道共用 | 远道更细更暗，近道稍宽稍亮；用断续高光让玩家看出航道，**不要整道发白** |
| 验收三条 | ①看得出同一片海的远近 ②辨得清船在哪一道 ③看得出船底贴着水 |
| 首轮范围 | 小水花、尾流、炮弹水柱、巨浪**延后**，等基础海面定下来再派 |
