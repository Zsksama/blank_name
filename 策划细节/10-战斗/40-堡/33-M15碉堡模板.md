# 二、堡是什么（定位）

> **堡是"守不住的地方"，也是"守的理由"。**

| 身份 | 具体是什么 | 玩家感受到的 |
| --- | --- | --- |
| **火力底座** | 每条道有没有炮决定有没有输出；没炮的道就是盲道 | "这条道得我自己去" |
| **家** | 堡破 = 本场失败；敌人从水门灌进来（船沉不算失败） | "不能让它塌" |
| **船的门** | 水门在中道，是玩家船的出入口，也是敌人破堡后的入口 | "守住门" |

**设计红线**：任何一条道，堡的火力都不能和玩家的操作等值。堡是"替你看一半"，不是"替你看全部"。

## 3.2 航道与水门

| 航道 | 位置 | 初期炮位 | 说明 |
| --- | --- | --- | --- |
| 道 1（上） | 最上 | 1 门 | |
| 道 2 | | 1 门 | |
| **道 3（中）** | **中** | **0 门** | **水门所在道**。船从这里出入；门洞占位，初期不装炮 |
| 道 4 | | 1 门 | |
| 道 5（下） | 最下 | 1 门 | |

- **开局 4 门炮**，道 3（水门道）为盲道
- 水门是玩家船的**出生点、回港点与复活点**（都走一个进出水门的动画）
- 敌人破堡后**从这里灌进堡内**

**水门耐久**：**不做独立血量，与堡血同体**——堡血归零 ＝ 水门被打破。

> 这条结构一句话：**船的家和堡的命门，是同一个门。**

## 3.3 盲道模型（已定）

1. 堡的输出**按道**算，不看距离
2. **炮能打到近处**，符合史实（敌台铳眼离地 20—30 cm，专打墙根）
3. 某条道没有炮 → 该道**零堡输出**
4. 后期可一道两门，形成"相对盲道"
5. 水门道**永远最多 1 门**，所以永远是最弱的一条 = 玩家主守道

**已废案**：曾提"贴墙一段死角"，与史实冲突（低孔专打墙根），取消。

## 3.6 画面（【建议】，未定，留待你详细设计）

- **三段式**：水下石砌基座 → 墙身 → 顶部敌台；别画成一整块方盒子
- 墙身用史料做法：**块石 + 丁头石斜筑，中间片石灌黄沙冲实**

# 四、火力规则

## 4.1 开火

| 项 | 规则 |
| --- | --- |
| 触发 | 本道有敌船即自动开火 |
| 目标 | 本道**最靠左（最接近堡）**的敌船 |
| 弹道 | 直射，不做抛物线 |
| 命中判定 | 与 M4 同：打帆穿过，打舰体/炮台停 |
| 弹药 | 不消耗（首版） |
| **误伤** | **不会误伤玩家船**（体验优先，已定） |
| 后坐力 | 无 |

## 4.2 数值占位（只填位，后续完善）

| 项 | 值 | 折算 |
| --- | --- | --- |
| 单发伤害 | 6 | |
| 冷却 | 3 s / 门，各门独立 | 4 门 ≈ 8 dps（分在 4 条道） |
| 射程 | X ≤ 400 | ≥ 敌人 attack range 400 |
| 散布 | 0 | |

> 对比玩家：2 门 × 12 伤 / 5 s ≈ 4.8 dps。堡在**有炮的道上**更强，但**只覆盖 4/5 条道**。

## 4.3 敌人在盲道里

**和正常道路完全一样**：推进 → 到 `stop_distance` 停 → 持续开火打堡。不绕行、不找有炮的道。

## 4.4 多道同时开打

- 敌人**各自独立处理攻击行为**，不排队，可多道同时压上
- 堡的炮各自为战，不跨道支援
- 结果：同一时刻可能有 2—3 条道在挨打，玩家必须取舍

# 五、受击、灯火与判负

## 5.1 敌人怎么打堡

| 项 | 规则 |
| --- | --- |
| 位置 | 进入 `stop_distance = 320` 后停船 |
| 行为 | 持续远程开火，**不冲撞、不自毁、不登岸** |
| 接舷战 | **堡不触发接舷战** |
| 伤害 | 与 M12 一致（E-01：8 dmg / 3 s） |

## 5.2 掉灯火（接 `14` 号）

| 堡血跌破 | 灯火 | 次数 |
| --- | --- | --- |
| 60% | −8 | 一局一次 |
| 25% | −12 | 一局一次 |
| 归零 | −25 | 一局一次 |

## 5.3 水门被破（PvZ 式）

```
堡血 ≡ 0（＝水门被打破）
  → 演出：敌人驶向水门 → 走上岸 → 走进门里
  → 动画结束，本场战斗失败
       ├─ 兜底次数 > 0 → 消耗一次 →「乡兵击退了倭寇」→ 重整，下一场继续
       └─ 兜底次数 = 0 → 触发结局
```

- 演出做到"**敌人走近水门并走进去**"即可，不做大规模攻城动画
- 动画结束即结算，**不做长时间慢镜头**
- 船沉不算失败：扣灯火，下一场从水门再出（动画）
- 兜底次数：简单 3 / 普通 2 / 困难 1

**防烦人**：同一条提醒有冷却；多道同时开打**合并成一条**，不叠加。

**三条忌讳（已写进策划案，勿犯）**：

1. **「鸣金」不能用** —— 明代鸣金＝收兵/退兵，用反了。警报只能写"鸣金鼓""擂鼓敲锣"
2. **礼炮不当警报** —— 官方素材里的"鸣炮""礼炮齐鸣"全是祭祀与出巡（PDF 130、484）
3. **「狼烟」南方不合制** —— 戚继光原话「南方狼粪既少，烟火失制」，改草屋举火

另两条口径：「塘报」是文书不是喊话；「烽堠举火」是墩台接力，我们敌台就在眼前，只能当氛围。
