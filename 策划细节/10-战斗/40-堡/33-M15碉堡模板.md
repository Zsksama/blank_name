# 二、堡是什么（定位）

一句话：

> **堡是"守不住的地方"，也是"守的理由"。**

三重身份，缺一个它都会退回成一座塔：

| 身份 | 具体是什么 | 玩家感受到的 |
| --- | --- | --- |
| **火力底座** | 若干固定扇区，扇区外的航道它管不着 | "这条道得我自己去" |
| **家** | 堡破 = 本场失败（船沉不算） | "不能让它塌" |
| **墙上的眼睛** | M11 望楼预留：堡标记的目标，玩家打有加成 | "它在帮我看" |

**设计红线**：堡永远不能覆盖全场。一旦能，玩家就没活干了——这是 `09` 号 B05 那句「强度一高玩家就没事做」的直接执行。

# 三、结构

## 3.1 画面占位

| 项 | 值 | 说明 |
| --- | --- | --- |
| 位置 | 画面最左 | 你画的草图与 H01 一致 |
| 占位宽 | X = 0—120 px | 【占位】美术出图后回填 |
| 高度 | 贯穿全部航道 | 敌台露出水面的部分 |

## 3.2 炮位

| 项 | 值 |
| --- | --- |
| 初始炮门 | **2** |
| 满级炮门 | **4** |
| 朝向 | **固定朝右**，不可旋转（与玩家炮的 0—180° 转塔不同） |
| 布置 | 炮位按航道纵向排布，每门占一个扇区 |

> **为什么固定**：敌台的炮开在铳眼里，本来就不能转。这条既省程序，又让"扇区"这个概念站得住。

## 3.3 扇区模型（核心）

```
航道 0  ┌──────────┐  ← 内道：永远盲，炮打不到
航道 1  ├──────────┤  ← 炮位 A 的扇区
航道 2  ├──────────┤  ← 炮位 A 的扇区（或 B）
航道 3  ├──────────┤  ← 炮位 B/C 的扇区
航道 4  └──────────┘  ← 炮位 C/D 的扇区
```

**规则**：

1. 航道总数记为 `lane_count`，当前 **5**（从你的草图数出，【待确认】）
2. **内道（最靠近堡的那条）永久为盲道**：炮口在墙身上，打不到自己的墙根 —— 这是史料里的墙根盲带（S-01）
3. 其余 `lane_count − 1` 条道可以布炮
4. 炮门上限 = `lane_count − 1`，所以 5 条道时最多 4 门
5. 盲道在 UI 上必须能被玩家认出来（见 7.2）

> **这条规则的好处**：航道数、炮门数、升级上限三件事被一个公式锁死，以后加航道也不会出现"堡能全覆盖"。

## 3.4 血量与破损档

| 项 | 值 | 说明 |
| --- | --- | --- |
| 总血量 | **400** | 【占位】交数值组 |
| 破损档 | 100% / 60% / 25% | 用于表现 + 掉灯火 |
| 部位 | **不做**（单一血条） | 你已定：门/墙拆分不做 |

> 注意：**堡没有部位、没有传导、没有舵**。M4 那套三箱规则只适用于船。

# 四、火力规则

## 4.1 开火

| 项 | 规则 |
| --- | --- |
| 触发 | 扇区内存在敌船即自动开火，不需玩家操作 |
| 目标 | 扇区内**最靠左（最接近堡）**的敌船 |
| 弹道 | **直射**，不做抛物线（堡在高处，俯射水面） |
| 命中判定 | 与 M4 同规则：打帆穿过去，打舰体/炮台停 |
| 弹药 | **不消耗**（首版）。理由：敌人在堡射界内时正是玩家最缺弹的时刻，共用弹药池会变成"抢弹" |
| 后坐力 | 无（堡是石构，不做视觉后坐） |

## 4.2 数值占位

| 项 | 值 | 折算 |
| --- | --- | --- |
| 单发伤害 | 6 | |
| 冷却 | 3 s / 门，各门独立 | 2 门 ≈ 4 dps |
| 射程 | X ≤ 360 | 略大于敌人 `stop_distance = 320`，保证打得到停下来的船 |
| 命中率 | 100%（直射，无散布） | 堡不做"打歪"，会削弱可读性 |

> 对比玩家：2 门 × 12 伤 / 5 s ≈ 4.8 dps。**堡略低于玩家，且管不全**——兜底可以，替不了你。

## 4.3 敌人在扇区里会怎样

- 敌船进入扇区 → 被堡点掉（E-01 舰体 40，2 门约 10 s 打沉一艘）
- 敌船停在 `stop_distance = 320` 打堡 → 正好落在堡的射程内，形成**互相消耗**
- 所以：**扇区内的敌人是"堡用时间换掉的"，盲道里的敌人是"玩家必须亲自去的"**

# 五、受击、灯火与判负

## 5.1 敌人怎么打堡

| 项 | 规则 |
| --- | --- |
| 位置 | 进入 `stop_distance = 320` 后停船 |
| 行为 | 持续开火，不冲撞、不自毁 |
| 伤害 | 与 M12 敌人模板一致（E-01：8 dmg / 3 s，射程 400） |

## 5.2 掉灯火（接 `14` 号）

【建议】按档掉，不按次掉。原设计写"到阈值后再受击"，若每次受击都掉，一局能掉几十次，数字就废了。

| 堡血跌破 | 灯火变化 | 触发次数 |
| --- | --- | --- |
| 60% | −8 | 一局一次 |
| 25% | −12 | 一局一次 |
| 归零 | −25 | 一局一次 |

## 5.3 判负

```
堡血 ≡ 0
  ├─ 本场战斗失败
  ├─ 兜底次数 −1（简单 3 / 普通 2 / 困难 1）
  └─ 兜底次数归零后再失败 → 本局失败 → 回档 或 进结局
```

- **船沉不算失败**（S-05）：船沉会扣灯火并进入重整，下一场从堡再出
- 堡归零后**立即进入结算**，不做"被继续打几秒"的慢镜头（【待定】，见第九节 Q6）

# 六、修复与升级

## 6.1 修复

| 场合 | 规则 | 说明 |
| --- | --- | --- |
| 战斗中 | 【待定】是否自动修复 | `25` 号 M6 写"修船只与碉堡，战斗中有自动修理"，但堡若修太快会打不动 |
| 经营后 | **修到 70%，免费**【建议】 | 与船的 60% 上限形成对比：打仗修不满，休整能修回来 |
| 剩余 30% | 经营里花材料修 | 接 `12-经营玩法` |

【建议】战斗中堡**不自动修复**，或只做极慢（占位 1 HP/s）。理由：堡的血是本场战斗的"时间压力表"，能自愈就失去了压迫感。**请拍板**。

## 6.2 升级（`堡Ⅰ / 堡Ⅱ / 堡Ⅲ`）

| 级 | 效果 | 说明 |
| --- | --- | --- |
| **Ⅰ 基础** | 2 门炮 | 开局 |
| **Ⅱ** | **3 门炮** | +1 门，覆盖多一条道 |
| **Ⅲ** | **4 门炮** | +1 门；5 条道时正好只剩内盲道 |

- **每级只加一门炮**，不加血、不加射程——保持"升级＝多管一条道"这一个清晰概念
- 血量和射程的提升做成经营侧的其他节点（接 M5），不塞进堡等级
- 顶部 UI 显示 `堡Ⅰ/Ⅱ/Ⅲ` + 破损度百分比

> 【待定】Ⅲ级要不要额外给点东西（比如瓮城外观、第二座敌台）。史料有瓮城（只有东门有），但那是结构改变，成本高。

# 七、表现与 UI

## 7.1 顶部状态栏

| 元素 | 内容 |
| --- | --- |
| 等级 | `堡Ⅰ`（草图里写的"堡Ⅲ"位置） |
| 破损度 | 百分比 + 三档变色 |
| 炮位 | 4 个小格，已解锁亮、未解锁暗 |

## 7.2 盲道提示（关键）

玩家必须一眼看出"这条道堡管不着"。三种做法，选一：

| 方案 | 做法 | 成本 |
| --- | --- | --- |
| A | 航道上叠一层**虚线/暗色** | 低 |
| B | 堡的**铳眼视锥**在画面上画出来（开发者模式同款） | 中 |
| C | 只在 HUD 用一个小图标提示 | 低，但不好看 |

【建议 A + 开发者模式叠加视锥】，正式画面用虚线，调试时能看精确边界。

## 7.3 受击表现

- 城墙碎石 + 尘土
- 破损档切换时：冒烟加重、灯火变暗（接 `14` 号灯火）
- 堡被持续攻击时，屏幕边缘轻微震动（可选）
