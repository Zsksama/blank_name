# 二、堡是什么（定位）

> **堡是"守不住的地方"，也是"守的理由"。**

| 身份 | 具体是什么 | 玩家感受到的 |
| --- | --- | --- |
| **火力底座** | 炮按航道布，哪条道有炮哪条道就有输出 | "这条道堡不管，我得去" |
| **家** | 堡破 = 本场失败；敌人从水门灌进来（船沉不算失败） | "不能让它塌" |
| **船的门** | 水门在中道，是玩家船的出生/回港/复活点，也是敌人破堡后的入口 | "守住门" |

**设计红线**：堡不能替玩家覆盖全场。它替你守一半，另一半是你的。

## 3.2 航道与水门

| 航道 | 初期炮位 | 说明 |
| --- | --- | --- |
| 道 1（上） | 1 门 | |
| 道 2 | 1 门 | |
| **道 3（中）** | **0 门** | **水门所在道**：门洞占位，开局不装炮 |
| 道 4 | 1 门 | |
| 道 5（下） | 1 门 | |

- 开局 **4 门**
- 水门是玩家船的**出生点、回港点、复活点**
- 敌人破堡后**从这里灌进堡内**
- **水门不做独立血量**，堡血归零 ＝ 水门被破

> **船的家和堡的命门，是同一个门。**

## 3.3 火力覆盖：没有"盲道"这个概念

**11-24 定案：删掉 `blind_lane`，不再有"盲道"这个设定。**

| 规则 | 内容 |
| --- | --- |
| 发射条件 | **该道有炮** ＋ **该道有敌船** |
| 没有炮的道 | 自然不发射——原因是"没炮"，**不是因为它被标记成盲道** |
| 近处 | **能打**（敌台铳眼离地 20—30 cm，专打墙根） |
| 提示 | **不做任何盲道/弱道提示**。玩家看左边有几门炮、几个炮口，就知道哪条道火力弱 |

- 代码层：**删除 `blind_lane` 变量**；`build_turrets()` 只在有炮位的道上生成炮
- 开局 5 条道里 4 条有炮、中间水门道没有；升级后水门道也能有 1 门

## 3.4 炮位与升级（接口，数值后定）

| 项 | 规则 |
| --- | --- |
| 每道炮位上限 | 2 门 |
| 水门道炮位上限 | 1 门（门洞占位） |
| 开局 | 道 1/2/4/5 各 1 门 = 4 门；道 3 = 0 |
| 首次升级 | 道 3 补 1 门 |
| 总上限 | 首版 6 门【建议】 |
| 细节 | 不在本模块定，归经营场景升级部分 |

## 3.5 血量与破损四档

**船的部位是三档；堡是四档**——因为"门没了"是玩家看得见的一个状态，值得单独一张图。

| 血量比例 | 档 | 表现 |
| --- | --- | --- |
| 1.0—**0.6** | **完整** | 雉堞齐整、水门完好 |
| 0.6—**0.25** | **破损** | 墙皮崩落、雉堞缺角、冒烟 |
| 0.25—0 | **破坏** | 墙体破口、水门半塌、火光 |
| **0** | **门没了** | 水门洞开，敌人从这里涌入 |

- 阈值：**0.6 / 0.25**（不用船那套 0.75/0.10——0.1 会让人被一下打死，堡不该这么脆）
- 总血量 **400**（三档难度相同）
- 难度只改**出怪量与敌人强度**，不改堡血
- 部位：**不做**；传导/舵/帆：**无**

## 3.6 画面（【建议】，未定）

- **三段式**：水下石砌基座 → 墙身 → 顶部敌台；别画成一整块方盒子
- 墙身：块石 + 丁头石斜筑，中间片石灌黄沙
- 顶部：雉堞一排，中间一座望楼
- **铳眼**：外窄内宽、三面开孔，画成**小方孔**——不要画成圆形炮口
- **火炮口**：每门炮要有一个**比铳眼大的矩形开口**，正对本道、位于敌台正面中下部；炮从这里出。铳眼是打人的小孔，**两者并存**
- ⚠️ 常见错画：把炮管直接从铳眼伸出来，或把铳眼画成圆炮窗
- **水门**在中道正中：券门 + 闸槽 + 下落式木闸
- 灯火：夜里窗口有火光，越破越弱

# 四、火力规则

## 4.1 开火

| 项 | 规则 |
| --- | --- |
| 触发 | 本道有敌船即自动开火 |
| 目标 | 本道**最靠左（最接近堡）**的敌船 |
| 弹道 | 直射 |
| 命中判定 | 与 M4 同：打帆穿过，打舰体/炮台停 |
| 弹药 | 不消耗 |
| **误伤** | **不会误伤玩家船** |
| 后坐力 | 无 |

## 4.2 数值占位（只填位，后续完善）

| 项 | 值 |
| --- | --- |
| 单发伤害 | 6 |
| 冷却 | 3 s / 门，各自独立 |
| 射程 | **400** |
| 散布 | 0 |

**射程口径（重要）**：

- 模板敌船：停靠 `320`，攻击距离也在 **320—400** 内 → **停靠位双方都打得到，不出现真空**
- **后续特殊敌船可以有更远射程**——那时"它打得到你、你打不到它"是**刻意设计**

## 4.3 铳眼射击（11-25 新增）

堡除了火炮，还有**铳眼**：近距离平射，补近防。

| 项 | 规则 |
| --- | --- |
| 触发 | 本道有敌船进入**铳眼射程**（占位 200 px，比火炮 400 近得多） |
| 弹道 | **不生成实体炮弹**——贴脸距离太近，弹道没有意义，也省性能 |
| 结算 | 射程内直接判定命中：**命中位置出火星、敌舰体直接掉血** |
| 表现 | **开火动画（铳口火光）＋ 音效 ＋ 命中处飞溅** |
| 数值 | 伤害 2 / 发，间隔 1.2 s（占位） |
| 归属 | 只有**有敌台的道**才有铳眼；水门道没有（门洞不是敌台） |

- **美术本轮只画火光**；**水花暂不画**，等做海浪/水花那一轮一起补（记录点，别忘了）
- 与接舷的关系：敌船贴上来之前会被铳眼削一口——可作为接舷前的压力，接口先留，不深度联动

## 4.4 多道同时开打

- 敌人各自独立处理攻击行为，不排队
- 堡的炮各自为战，不跨道支援
- 同一时刻可能 2—3 条道在挨打，玩家必须取舍

# 五、受击、灯火与判负

## 5.1 敌人怎么打堡

| 项 | 规则 |
| --- | --- |
| 位置 | 进入 `stop_distance = 320` 后停船 |
| 行为 | 持续远程开火，不冲撞、不自毁、**不登岸** |
| 接舷战 | **堡不触发接舷战** |
| 伤害 | 与 M12 一致（E-01：8 伤 / 3 s） |

## 5.2 掉灯火

| 堡血跌破 | 灯火 | 频率 |
| --- | --- | --- |
| 0.6 | −8 | **每场战斗一次** |
| 0.25 | −12 | 每场战斗一次 |
| 0 | −25 | 每场战斗一次 |

- **重置粒度 = 每场战斗**：堡战斗中不修，经营修好后再打就是新的一场，三档重新计
- 同一场里回血再掉回同一档，**不重复触发**

## 5.3 破堡与判负

```
堡血 ≡ 0（＝水门被破，门没了）
  → 取「离水门最近的那一艘敌船」驶向水门 → 走上岸 → 走进门里
  → 演出结束 → 本场战斗失败
       ├─ 兜底次数 > 0 → 消耗一次 →「乡兵击退了倭寇」→ 重整，下一场继续
       └─ 兜底次数 = 0 → 触发结局
```

- 兜底次数：简单 3 / 普通 2 / 困难 1
- **船沉不算失败**：扣灯火，下一场从水门再出
- **演出期间立刻冻结玩家操作**（不能移动、不能开火），只看演出
- **「门没了」贴图在血归零那一瞬间就切**，不等演出结束
- 不做长时间慢镜头

# 七、表现与 UI

## 7.1 顶部状态栏

`堡Ⅰ/Ⅱ/Ⅲ` + 破损度百分比 + 炮位格（已解锁亮、未解锁暗）。

## 7.2 不做任何"盲道提示"

- **删掉虚线、删掉色块、删掉提示文字**
- 玩家靠**堡上的炮口**判断哪条道火力弱——这是最自然的读法，不用教
- 开发者模式若需要调试，可以另做一层可视化，但**正式画面不出现**

## 7.3 警报文案（带出处）

**触发**：敌人靠近并开始稳定输出之后才显示，不是一进入射程就弹。

| 场景 | 文案 | 出处 |
| --- | --- | --- |
| 敌船靠近 | **贼船出没** | 《纪效新书》卷十七·守哨篇 |
| 首次被攻击 | **贼攻城** | 同书·守城号令 |
| 破损过半 | **台已半圮** | 借官方「火烈台圮」·**游戏化造词** |
| 被攻破 | **城陷矣** | 官方「如城陷则我等不知死所」 |
| 援兵到来（预留） | **义兵来集** | 官方「王氏义兵来集」 |

- 同一条提醒有冷却；多道同时开打**合并成一条**
- 语音后面再补

**三条忌讳**：①「鸣金」＝收兵，用反 ②「礼炮/鸣炮」是祭祀，不作警报 ③「狼烟」南方不合制

## 7.4 破损四档贴图

见 3.5 的表。0 档那张就是"**门没了**"——水门洞开，四张图到此为止。

保留，后续有空再做；当前只留 `is_marked` 字段，不生效。
