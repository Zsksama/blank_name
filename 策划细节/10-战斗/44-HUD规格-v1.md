## 二、逐元素规格

### 2.1 暂停键（左上角）

- 形态：三条竖线图标，点击 → **屏幕变灰**
- **本轮不做暂停菜单**（后续加"继续 / 音量"）

### 2.2 弹药数量（左上第一行）

- 三个**胶囊框**：`弹1 [n]` 等
- **必须显示剩余数量**（这是核心信息）
- 数量为 0：框变灰；**再点击 → 闪烁 + 音效 + 一句台词**
- 数据：`round / chain / grape` 三个仓

### 2.3 部位血量（左上第二行，**五个小圆圈**）

- **环形填充**，填充**要细**（建议线宽 2—3 px）
- 颜色即状态：**绿 = 完好 / 黄 = 破损 / 红 = 破坏**（阈值 75% / 10%，与代码一致）
- **鼠标移上去** → 显示名称 + 百分比
- 建议顺序：**帆 / 舰体 / 火器与弓手 / 舵 / 撞角**（与代码数组一致；要改成你画的 撞/炮/舰/帆/舵 也行，一句话就能换）

### 2.4 灯火（顶部中央）

- **大圆环**，独立占位，**不套部位血量**
- 数值显示（0—100）
- **接舷时位置不变**（唯一不动的元素）

### 2.5 沉敌数（灯火下方）

- 文字：`沉敌数：8`
- **每次变化加特效**（要求：像火烧过一样的炫酷过渡）
- 本轮先做数值 + 简单动效，火焰特效可后补

### 2.6 关卡名 / 敌人数量（右上）

- 关卡名（现用日期，如 `1558-05-02`）
- 敌人：`11 / 19` —— **分母是名单总数**（不是同屏上限 15），分子是已击沉/已解决数

### 2.7 堡血条（左侧竖条）

- 竖条 + 百分比
- **不显示炮位门数**——炮位由**堡贴图**自己表现（`■■■■□□` 那套删掉）
- 堡四档外观已由贴图承担，HUD 不重复表达

### 2.8 气焰条（右侧竖条）

- 竖条，表示 `当前敌人数 / 初始敌人数`
- **四档刻度暂缓**（与其它补充项一起，等体验优化批）
- 本轮先要"能看出在降"

### 2.9 装填冷却（左下圆环）

- 圆环**分两段**（两门炮各自进度）
- **剩余时间数字直接写在环上**（不要另起文字）
- 圆环**中间切三块** = 弹药选择；**当前选中高亮**
- 圆环**右侧两个框** = 齐射 / 单射；当前高亮
- **切换时：发光框左右滑动**到新选项

### 2.10 提示行（底部居中）

- 半透明显示，**鼠标移上去变不透明**
- 内容：`鼠标瞄准 · 左键开火 · 1/2/3 换弹 · Q 切换齐射 · A/D 航行 · W/S 换道`
- **新手教程先做**，提示行是它的兜底

### 2.11 余败场（**位置待定**）

- **不要直接写文字**（主策划要求）
- 方案：用**图标暗示**（小旗 / 小锚 / 抽象符号，剩几条画几个）
- 位置后续再定，本轮**先不做**

## 三、接舷时的收缩规则

| 元素 | 接舷时 |
| --- | --- |
| 弹药数量、部位圈、装填环、齐射框 | **整体上移**，让出中间与底部空间 |
| **灯火** | **不动**（唯一固定） |
| 接舷现有 UI（双方血条 / QTE / T 长按） | **暂时保留原样**，后续再统一 |

---

## 四、缩放适配

- 1280×720 为基准布局
- 窗口变大（如 2544×1422）时**按锚点缩放**，不重排
- 全屏 / 窗口切换不能错位
