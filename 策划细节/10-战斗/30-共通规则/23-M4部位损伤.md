# 二、先解释你看不懂的两条

## 2.1 第 4 条「三档阈值」是什么

部位血量不是只有"好的/坏的"，中间还有一档。所以要定两个分界百分比：

```
100% ─────── 75% ─────── 10% ─────── 0%
     正常        破损        被破坏
```

**已定：`[0.75, 0.1]`**（≤75% 破损，≤10% 被破坏），暂定，后续可能随数值与升级调整。

## 2.2 第 6 条「部位上限是否随升级提升」是什么

问的是：升级能不能**提高某个部位的血量上限**。

**已定：部位血量本身是绝对值（不是百分比），这个数值就是设计成可升级的；百分比只是显示层换算。**
所以升级改的是 `max_hp` 这个数值，UI 按 `当前 / 上限` 画百分比。

# 三、分区（已定：3 个碰撞箱）

| 碰撞箱 | 位置 | 性质 | 备注 |
| --- | --- | --- | --- |
| **帆** | 上层大块 | 软（穿透） | 炮弹穿过，继续飞 |
| **舰体** | 中层主体 | 硬（阻挡） | 血量归零即沉 |
| **炮台** | 中层前部小块 | 硬（阻挡） | 停下，并伴随舰体伤害 |

**不进碰撞箱、但仍存在的部位**：

| 部位 | 怎么受伤 |
| --- | --- |
| **舵** | 命中舰体/火器与弓手时，按概率随伤害传导过去 |
| **撞角** | 同上 |

这样做的好处：碰撞检测只有 3 个箱，性能最好；舵与撞角靠"随机 + 传导"受伤，既让它们存在，又不用为小船做精细碰撞。

### 传导的具体规则（建议，待你调）

| 主命中 | 传导目标 | 概率 | 传导伤害比例 |
| --- | --- | --- | --- |
| 舰体 | 舵 | 15% | 主伤害的 30% |
| 舰体 | 撞角 | 10% | 主伤害的 30% |
| 炮台 | 舵 | 10% | 主伤害的 30% |
| 炮台 | 撞角 | 10% | 主伤害的 30% |
| **帆** | **不传导** | — | 打帆只伤帆（已确认） |

> 这条与"软/硬穿透"并行，不冲突：穿透管**炮弹去哪**，传导管**打不到的部位怎么被波及**。

### 跨道判定（重要，见 `26-议题-跨道命中判定.md`）

炮弹与船都必须带 `lane_index`，**碰撞前先比对航道**：
- 同道 → 正常判定（帆穿透、舰体/火器与弓手停弹）
- 跨道 → **直接穿过**，不结算、不消失

原因是 2D 侧视里炮弹的抛物线会划过别的航道贴图，纯几何判定会误伤。
爆炸弹的 AoE 也只在同道内生效。

### 部位破坏的严重性（已确认）

- 舵、撞角被破坏**不致命**，只是大幅降低效率
- **只有舰体血量归零才沉没**
- 这样随机传导带来的是麻烦，不是败局，玩家不会觉得"不是我操作的问题"

### 部位损伤对行为的影响（敌我通用）

部位不是只掉血，它要**直接改对方的参数**，否则"打帆减速、打炮哑火"只是数字。

| 部位状态 | 影响对象 | 效果 |
| --- | --- | --- |
| 帆 破损 / 被破坏 | 移动速度 | ×0.7 / ×0.4 |
| 炮台 破损 / 被破坏 | 装填间隔 | ×1.3 / **完全无法开火** |
| 舵 破损 / 被破坏 | 换道耗时 | ×1.4 / 无法换道 |
| 撞角 破损 / 被破坏 | 撞击伤害 | ×0.5 / 无法撞击 |
| 舰体 归零 | — | 沉没 |

> 这套 debuff **对玩家船和敌船一视同仁**（你已定：敌我一套规则）。
> 行为树只读 `speed`、`attack_cd` 的最终值，不自己判断部位状态——判断在部位逻辑里做。

# 四、你说的"炮弹穿透"其实比传导更好

你第 3 条的设想是：

> 打中帆 → 炮弹不消失，继续飞 → 撞到舰体才停

这比我原来写的"相邻部位吃 50% 传导"高明，因为它**把传导变成了空间关系**，玩家能看见：

| 部位 | 命中后 | 原因 |
| --- | --- | --- |
| 帆（软） | 炮弹**穿透**，帆受伤，炮弹继续飞 | 帆是布，挡不住炮弹 |
| 炮位（硬） | 炮弹**停止**，炮位受伤，**同时舰体也受伤** | 炮位背后就是舰体 |
| 舰体（硬） | 炮弹停止，舰体受伤 | — |
| 舵（硬） | 炮弹停止 | — |

**建议：用这个"软/硬穿透"模型取代传导伤害**，规则更直观、更好调，也更好做特效（帆被打穿时飘一块布）。

需要程序注意的三点：

1. **同一发炮弹对同一艘船的部位，每个部位只结算一次**（防止穿过去又穿回来重复扣血）
2. 帆穿透后继续飞，可能再打中舰体 → **一炮两伤**，这个威力要在数值上算进去
3. "炮位受伤同时伤舰体"要实现成一个显式的伴随伤害系数，别藏在碰撞箱重叠里
