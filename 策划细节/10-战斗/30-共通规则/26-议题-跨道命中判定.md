# 二、问题是怎么产生的

我们的世界是 **2D 侧视**，但设定上有多条**并排的航道**（相当于深度不同）。这两件事天然冲突：

```
玩家视角（2D）              设定（3D）
 ┌────────────────┐
 │ ▔▔▔ 帆          │  ← 炮口在这条道
 │  ●→  炮弹弧线    │
 └────────────────┘
 ┌────────────────┐
 │   🚢 敌船         │  ← 另一条道的船
 └────────────────┘
```

炮弹是一条抛物线，画面上会**穿过另一条道的敌船贴图**。如果只按"几何相交"判定，就会出现：**打 A 道的炮弹把 B 道的船打中了**。

更麻烦的是：帆部位很高、爆炸弹有半径，两个都会让"视觉重叠"变成常态，而不是偶发。

# 三、四个方案

| 方案 | 做法 | 成本 | 副作用 |
| --- | --- | --- | --- |
| **A 纯航道过滤** | 炮弹带 `lane_index`，只与同道的碰撞箱判定 | 极低 | 视觉上"穿过敌船却没伤害"，玩家会觉得是 bug |
| **B 航道过滤 + 视觉补偿** | 在 A 上加：分道明暗差、炮弹图层、当前道高亮 | 低 | 需要美术配合一点 |
| **C 跨道概率命中** | 允许打到邻近道，按概率/衰减结算 | 中 | 引入运气，玩家说不清为什么中/不中 |
| **D 真 3D（加 z 轴）** | 炮弹与船都有 z，按 z 判定 | 高 | 16 天内不现实 |

**我的建议：B**。技术上等同 A（一行过滤），额外只要美术配合一点点，就能把"穿模感"压到最低。

具体三件事：

1. **炮弹只与同 `lane_index` 的船判定**（帆、舰体、炮台都一样）
2. **视觉分层**：不同航道用轻微明暗/水线错位区分"远近"，炮弹画在自己航道的图层上
3. **发射时给一条极短的水道高亮**（或炮口脚下的一道光），告诉玩家"这一炮属于这条道"

# 四、必须一起定的边界情况

| # | 情况 | 建议 |
| --- | --- | --- |
| 1 | **爆炸弹的 AoE** | 半径只作用**同一条道**的船；不跨道 |
| 2 | **齐射多发的散布** | 散布只在竖直面上展开，不跨道 |
| 3 | **破帆弹穿帆后继续飞** | 仍在原道内继续；进入别的道不判定 |
| 4 | **敌方炮弹打玩家** | 同一套规则（敌我同规则，你已定） |
| 5 | **接舷战 / 撞击（M8）** | 同样只在同道判定，跨道不撞 |
| 6 | **预览线跨过别的道** | 允许画过去，但视觉上要弱化，避免暗示"能打到" |
| 7 | **两船贴在同道** | 正常判定，谁先接触谁吃伤害 |
