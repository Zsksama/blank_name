## 三、图层栈（这是这次返工的核心）

### 3.1 旧做法（错）

```
Background
Sea（一大块，盖住背景）
Land
Lanes（分割线）
PlayerShip / Enemies / Projectiles
```

→ 结果：海是一整块色，天空没了；炮弹掉进水里还能看见；船底沉下去也没被水挡住。

### 3.2 新做法：**每一道是一组，从远到近依次叠**

```
背景（整张：天空 + 远岛 + 海面，永远在最底）
├─ 第 0 组（最远）
│    ├─ 海平面 P1 线
│    ├─ 本道内容（船、炮弹、水花）
│    └─ 水体带：P1 → P2
├─ 第 1 组
│    ├─ 海平面 P2 线
│    ├─ 本道内容
│    └─ 水体带：P2 → P3
├─ 第 2 组（水门道）
├─ 第 3 组
└─ 第 4 组（最近）
     ├─ 海平面 P5 线（窗口底边）
     ├─ 本道内容
     └─ 水体带：P5 → 720（实际上没有，就是窗口底）
```

**为什么必须这么排**：

- 每道的**水体带只盖自己那一条**（115.2 px 高），不跨道 → 下面的海平面不会再去遮上面的背景
- 水体带**排在"本道内容"之后** → 船底沉下去、炮弹掉下去，会被**本道的水色盖住**，视觉上就是"没入水里"
- 下一组整体在上面 → 更近的一层自然压住更远的一层

### 3.3 z_index 建议

| 层 | z | 说明 |
| --- | --- | --- |
| Background | -100 | 整张，不再有第二块大海 |
| 第 i 组的海平面线 | `10 + i*4` | |
| 第 i 组的船/炮弹/水花 | `11 + i*4` | 船的 z 要**随所在航道动态变** |
| 第 i 组的水体带 | `12 + i*4` | |
| Land（左侧陆地/堡） | 50 | 在船前面 |
| Crosshair | 60 | 保留 |
| HUD | CanvasLayer | 保留 |

> 关键：**船的 `z_index` 不是常数**，换道时要跟着 `lane_index` 重算，否则会沉错层。

### 3.4 水体带怎么画

| 项 | 要求 |
| --- | --- |
| 范围 | 只画 `P(i+1) → P(i+2)` 这一条，**绝不允许整屏色块** |
| 颜色 | 深蓝，**透明度可调**：`water_alpha`（建议起始 0.85，程序做滑条让策划试） |
| 上边缘 | 一条 2—3 px 的亮边（水面反光），可以跟浪线共用一张贴图 |
| 浪线 | 后续美术会给波浪线素材；现在先用直线，接口留好 |

## 四、船与海平面

| 项 | 规则 |
| --- | --- |
| 骑线 | 船底**贴着本道底边那条海平面**（现有 `lane_bottom_y` 逻辑保留） |
| 正常状态 | 船底刚好压线，允许 **1—2 px** 沉入（看起来像"浮在水里"而不是"站在线上"） |
| 后坐力 | 允许船体**部分沉入本道海平面以下**，被水体带盖住 |
| 换道 | 换道过程**不沉**（现有 `lane_offset_y` 的换道插值保留） |
| 车道锁定 | **只在换道动画那零点几秒内**：不能左右移动、不能开炮；动画结束立刻解锁（已定） |

## 五、炮弹与水面

| 情况 | 期望表现 | 实现要点 |
| --- | --- | --- |
| 落进**本道**海平面以下 | 被本道水体带盖住（看不见了） | 炮弹 z 低于本道水体带 |
| 高抛**越过上方道** | **看得见**，从上方道的水面之上飞过 | 因为是"从远到近叠"，后画的近层在前，上层水不会挡下层高处的东西 |
| 出现在**下方道** | **绝不允许** | 跨道不结算（`26` 号）；视觉上也要被本道水挡住 |

> 一句话：**炮弹只能"消失在水里"，不能"出现在别的道里"。**

## 六、溅水花（验收器 + 保留为正式表现）

**这是你提出的验证手段，很好用，建议正式版也留着。**

| 项 | 要求 |
| --- | --- |
| 触发 | 炮弹落到本道海平面（入水瞬间） |
| 表现 | 在**海平面线上**生成一小簇水花 + 白色水柱，0.3—0.5 s 消失 |
| 层级 | 属于本道内容（在水体带**之前**画），所以水花在水面之上可见，入水部分被盖住 |
| 用途 1 | 让玩家看清"这颗弹打进水里了" |
| 用途 2 | **验收**：水花正常 = 图层顺序对了；水花被整个盖住或整个浮在水上 = 还错 |

## 七、验收四步（照着点）

1. **天空回来了**：画面最上方能看见天空/远岛，`Y<144` 区域没有任何海道线
2. **数线**：从 `Y=144` 开始往下数，一共 **6 条**海平面；最后一条贴着窗口底边
3. **沉船测试**：开一炮，船体往后退并**部分没入水色**，约 1 s 回来；把一条道的海平面隐藏，**上方背景不该有任何变化**
4. **水花测试**：把炮弹打进第 2 条道的水里，水花在线上炸开，**炮弹本体消失在水里**，且**不会**在第 3 条道出现
