# 二、三弹定案（方案为建议，你改）

## 2.0 总览

| ID | 名称 | 定位 | 一句话 | 史料底子 |
| --- | --- | --- | --- | --- |
| A-01 | **实心弹** | 通用输出 | 打得准、打舰体最疼 | 发熕石弹 / 佛郎机铅子，**高** |
| A-02 | **破帆弹** | 控制 | 双弹连链旋转，专撕帆 | 游戏化魔改（原型不作依据） |
| A-03 | **爆炸弹** | 范围 | 落点炸开，清一片 | 游戏化（替代纵火，成本更低） |

> 纵火弹（火球/火药桶/火砖）**留作加分项**，记在 `02-想法池.md`，本期不做。

## 2.1 A-01 实心弹

| 项 | 建议 |
| --- | --- |
| 形态 | 石弹/铅子，铁灰色圆球 |
| 弹道 | 重、下坠快、初速中等 |
| 命中 | 单体，硬部位停弹 |
| 特长 | 对舰体伤害最高 |
| 弱点 | 飞得慢、下坠快，远距离难打中 |
| 视觉反馈 | 命中出木屑与碎板，命中帆则穿个洞继续飞 |

## 2.2 A-02 破帆弹（链式双弹）

| 项 | 建议 |
| --- | --- |
| 形态 | **两个弹丸以链条相连，飞行中旋转** |
| 弹道 | 轻、初速高、下坠小（比实心弹更平直） |
| 命中帆 | **高倍伤害**（不做 buff，简化） |
| 命中舰体/火器与弓手 | 伤害很低（链弹是撕索具的，不是破船的） |
| 穿透 | 命中帆（软）**不消失**，继续飞；但后续命中的伤害大幅衰减 |
| 弱点 | 对舰体几乎无效，必须配合实心弹 |
| 视觉 | 旋转链条；命中帆时帆布被绞碎、绳索断裂 |
| **加分项（本期不做）** | 帆的**不同缺口位置**影响减速效果——技术与美术工作量不现实，记入想法池 |

**为什么这个魔改值得做**：它让"打帆"从"伤害数字"变成"看得见的动作"，而帆又刚好是减速与换道的开关——一炮打中帆，玩家立刻能感觉到对手慢下来了。

## 2.3 A-03 爆炸弹

| 项 | 建议 |
| --- | --- |
| 形态 | 黑球带引信，落地或命中后短暂延迟引爆 |
| 弹道 | 重、初速低、下坠明显（迫击炮感） |
| 命中 | **范围伤害**（半径约 60 px，占位） |
| 特长 | 一次打好几艘靠得近的船；对帆与炮台都有效 |
| 弱点 | 耗弹最多、装填最慢 |
| **自伤** | **按难度分**：简单不伤自己；普通 / 困难会对自己造成伤害（比例待定） |
| 视觉 | 引信火花 → 爆点火团 + 水柱 |

## 2.4 发射方式

| 方式 | 规则 | 耗弹 |
| --- | --- | --- |
| **单发** | 一门炮开火，出一发 | 1 |
| **齐射** | 所有就绪炮同时开火，扇形散布（建议 ±5°） | 打几发扣几发 |

> 史料侧：单发有佛郎机"子铳轮流贮药"支持；齐射的依据较弱（《阵纪》为二手转引），只作表现依据，写日志时标"游戏化"。

## 2.5 弹药 × 部位（占位伤害系数）

| 弹种 | 帆（软） | 舰体 | 炮台 |
| --- | --- | --- | --- |
| 实心弹 | 0.6 | **1.0** | 0.85 |
| 破帆弹 | **1.8** | 0.25 | 0.2 |
| 爆炸弹 | 0.7 | 0.85 | **0.95**（范围） |

配合 M4 的规则：帆是软部位（穿过去），舰体与炮台是硬部位（停下）。破帆弹打帆**穿过去**，正好符合它"撕完帆继续飞"的形态。

## 2.6 弹仓与换弹

| 项 | 结论 |
| --- | --- |
| 炮位 | **首版 2 门**，后续可升级，升级在经营模块设计 |
| 弹仓 | **三种弹各自独立计数**；**不设上限**，库存多少就能用多少 |
| 耗弹 | **射几发就是几发**，不做"每发耗多发"的差异 |
| 换弹 | 允许战斗中切换，**有一次切换延迟**（占位 1.5 s） |
| 补给 | 战斗中不补给；每场开始前由经营带入 |
| 齐射散布 | 有，占位 ±5° |
| 自伤 | 爆炸弹自伤**只做有/无**，不按比例 |
| 帆缺口细节 | 加分项，本期不做 |
