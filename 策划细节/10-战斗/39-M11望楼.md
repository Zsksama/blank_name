# 二、望楼是什么

> **望楼是堡的"眼睛"：它不替你打，它告诉你该先打谁、打哪儿。**

| 身份 | 具体是什么 |
| --- | --- |
| **选目标** | 永远锁定场上"最快"的那一艘 |
| **指位置** | 准星落在**该打的部位**上（不增加该部位伤害，只是提示） |
| **加伤害** | 被锁定的船**整船**受到更多伤害 |

# 三、规则

## 3.1 锁定（已简化）

| 项 | 规则 |
| --- | --- |
| **频率** | **没有间隔——随时都锁着一个** |
| 选谁 | 场上**横向速度最快**的那艘 |
| 数量 | **只锁一艘** |
| 重锁 | 当前目标**消失**（沉没或退场）→ **立刻**锁下一个 |
| 没有目标 | 场上无敌人 → 准星隐藏；一有敌人立刻锁 |

> 一句话：**望楼上永远有一个"正在看"的人。**

## 3.2 准星落点

准星不是笼统套在船身上，而是**落在该打的部位**：

| 敌人类型 | 准星落在 | 意思 |
| --- | --- | --- |
| **快船** | **帆** | "打帆，让它慢下来" |
| **普通船** | **火器与弓手** | "先打掉它的火力" |
| **重船** | **火器与弓手** | "先让它哑，再让堡收拾" |

- 帆被打烂后，准星**位置不变**（就挂在原处），**加伤照旧**
- **不配文字**——位置本身就是提示

## 3.3 加伤

- 被锁定目标：**整船受到的伤害 +50%**（占位，后续可升级）
- **对所有伤害来源生效**（玩家 + 堡）
- 不是"锁部位加伤"——准星在帆上，打舰体也一样加

## 3.4 失效

| 情况 | 处理 |
| --- | --- |
| 目标被击沉 | 立刻重锁 |
| 目标**撤退到场外** | 视同被击沉 → 立刻重锁 |
| **接舷期间** | **锁定冻结**（不重锁、不换目标），接舷结束恢复 |
| 堡被破 | **仍然有效**（望楼始终不失效） |

# 四、表现

| 项 | 做法 |
| --- | --- |
| 准星 | **旋转 + 放大缩小的循环动画**；颜色在**黄 ↔ 红**之间渐变 |
| 变黑 | **被锁的部位被打烂之后，准星变成黑色**（位置不变，表示"这块已经没了"） |
| 位置 | 套在目标的指定部位上，跟着目标移动 |
| HUD | 可选显示被锁目标的三个部位血条 |
| 音效 | 锁定瞬间一声轻响（后续音效模块定） |

> 黑色先试，看效果不好再改。

# 七、已定清单

| # | 结论 |
| --- | --- |
| 1 | **随时锁定**，没有 10 s 间隔 |
| 2 | 选**横向速度最快**的那艘 |
