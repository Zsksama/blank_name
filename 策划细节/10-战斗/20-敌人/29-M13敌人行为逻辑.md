# 二、行为树

## 2.1 黑板的共享数据（行为树的条件都读这些）

| 变量 | 来源 |
| --- | --- |
| `self_parts` | 自己各部位血量与状态（M4） |
| `morale` | 自己士气（M14 定义，行为树只读） |
| `lane_index` / `position` | 自己所在航道与坐标 |
| `lane_occupied[lane]` | 各航道是否已被占用（含其他敌船） |
| `player` | 玩家船位置、是否同道、距离 |
| `fortress` | 堡的位置、是否在射程内、剩余血量 |
| `attack_cd` | 装填是否完成 |

## 2.2 树形结构

```
Root（Priority Selector，从上往下第一个成功的分支执行）
│
├─ [1] Sequence: 已沉没？
│       ├ Condition: part_hp[HULL] <= 0
│       └ Action: SINK（沉没表现、结算、移出战场）
│
├─ [2] Sequence: 该撤了？
│       ├ Condition: morale <= retreat_threshold
│       └ Action: FLEE（掉头向右，离场销毁，不给奖励）
│
├─ [3] Sequence: 能打玩家？
│       ├ Condition: player.同航道 且 player.距离 <= attack_range
│       └ Action: ATTACK_PLAYER
│
├─ [4] Sequence: 能打堡？
│       ├ Condition: fortress.距离 <= attack_range
│       └ Action: ATTACK_FORTRESS
│
├─ [5] Sequence: 该前进？
│       ├ Condition: 前方无同航道友军（间距 > min_gap）
│       └ Action: ADVANCE
│
└─ [6] Fallback: HOLD（原地等待；前方被堵或目标都不在射程）
```

**关键点**：整棵树是**优先级选择**——能打玩家就先打玩家，打不到玩家才打堡，两个都打不到才继续往前走。这正好对应你第 3 点的规则。

## 2.3 每帧执行顺序

1. 读黑板（位置、距离、占用、装填）
2. 从根节点往下找第一个满足条件的分支
3. 执行该分支的动作（一帧只做一个动作）
4. 攻击动作不打断移动，除非处于 `ENGAGE`（见 2.4）

## 2.4 移动与攻击的并行

- `ADVANCE` 状态下：边前进边判断 [3][4]，一旦进入射程就切到攻击
- `ATTACK_FORTRESS` 时：**停在原地输出**，不再前进（对应你第 4 点"保持距离持续输出"）
- 停位距离 = `stop_distance`（与堡的距离，落在射程内）

# 三、目标选择规则（按你的第 3 点）

| 条件 | 行为 |
| --- | --- |
| 玩家**同航道** 且 距离 ≤ `attack_range` | 攻击玩家 |
| 否则，堡在 `attack_range` 内 | 攻击堡垒 |
| 两者都不满足 | **不攻击**，继续前进（或原地） |

- 不同航道**永远不打**玩家（与跨道规则一致）
- 堡的"距离"指敌船到堡前沿的距离，不是到画面左边界
- "不攻击"不是发呆：它会继续推进，直到进入堡的射程

# 四、移动与占位

## 4.1 不允许重叠

- 同一航道内，船与船之间保持 `min_gap`（占位：1.2 个船身）
- 前方 `min_gap` 内有船 → 本船**减速跟随**，不强行挤过去
- 空间不足 → `HOLD`（停在原地）

## 4.2 与堡保持距离

- 敌船推进到 `stop_distance`（例如 320 px）即停
- 停下后持续输出，不撞击（**首版没有撞击自毁**，与上一版不同，按你第 4 点改）

# 五、换道（规则已有，时机待定）

## 5.1 规则（按你第 2 点）

```
换道成功条件：目标航道无人
换道失败：目标航道有人 → 失败原因 = 【有人】，本帧不换，进入冷却
```

- 判定"有人"的粒度：目标航道内、与本船 x 距离小于某阈值（例如 1.5 个船身）
- 失败要能被调试面板看到（记录 `lane_change_fail_reason`）

## 5.2 什么时候选择换道

这是**待讨论**的：什么时候敌人会想换道？常见的几种动机：

| 动机 | 说明 |
| --- | --- |
| A 玩家在别的道，想去追 | 会让玩家没法躲 |
| B 自己这道被堵住 | 换道绕开 |
| C 换个道打堡 | 纯粹为了分散 |
| D 受击后规避 | 与"躲炮弹"有关 |

**【建议】首版：全部不做**（`can_change_lane = false`），把规则留在代码里但不启用。等行为树跑通、玩起来发现"敌人太死板"再加。
