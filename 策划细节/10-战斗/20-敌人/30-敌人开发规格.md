# 〇、先读这段

敌人这一版只做**一个模板 + 一个实例（E-01 倭船）**，目的是把"敌人"这件事拆成可配置的字段与一棵行为树。后面加快船、布雷船、大船，应该只改数据文件。

# 一、主策划原话与逐条解释

## 1.1 部位与穿透

> 1.命中部位按照坐标分区吧，到时候可能一艘船有多个碰撞箱，分别代表不同的部位，不知道会不会影响性能，可以记一下；如果影响性能，可能简单的靠y轴来计算。应该不会影响多少性能，我如果一个船是5个部位？场上顶多10艘船吧？可以先往细了做。（11-22 19:12）

**解释**：用碰撞箱实现部位判定；先按细的做，性能有问题再退化成 y 轴分区。

> 3.传导是否保留可以讨论，因为我想要用碰撞箱实现的话，比如帆，炮弹碰到了之后炮弹不会消失，继续飞行可以撞倒舰体，撞到舰体和武器这种就会消失，这样的话我撞到武器应该也会对舰体造成伤害。（11-22 19:12）

**解释**：帆是"软"部位，炮弹穿透不消失；舰体与炮台是"硬"部位，命中即停；命中炮台时**还要对舰体造成伤害**（伴随伤害）。

> 3.三个碰撞箱吧，对应帆，舰体和炮台，简单一点性能更好；但是撞角和舵可以保留，只是不单独列出碰撞箱，可以考虑用随机数+传导机制造成伤害。（11-22 19:30）

**解释**：只有 3 个箱；舵与撞角没有箱、有血量，靠"随机 + 传导"受伤。

> 1.阈值：[0.75,0.1]，暂定吧，后面数值特别处理过，也可能可以升级（11-22 19:30）

**解释**：血量比例 ≤0.75 进"破损"，≤0.10 进"被破坏"，两档各带 debuff。

> 1.这两个部位的破坏不致命，有道理，损坏只是大大减少原本的效率；只有舰体血量归零会导致沉没（11-22 19:26）

**解释**：舵/撞角被破坏不沉船；**只有 `HULL` 归零才沉没**。

## 1.2 敌我规则

> 7.敌我一套规则先（11-22 19:30）

**解释**：玩家船与敌船用同一套部位、穿透、传导、阈值规则，不要写两套。

## 1.3 模板与讨论边界

> 背景图大小已经定下来了1280*720，美术在对应的背景上自己对着画就行了；然后我们需要去完善敌人模板和碉堡模板的设计，先把敌人部分完成，先做一个敌人的模板出来（11-23 08:2x）

**解释**：画布 1280×720，美术按此作图；敌人先做模板。

> 1.身份表现是否合适暂时未知，需要程序进行开发后反馈，记录一下（11-23 08:31）

**解释**：`id/name/sprite/size/tint` 这些身份字段**先按现在这样，等程序做出来再回来调整**，不要当成定稿。

> 2.敌人的部位用数组存吧，eg[[帆，20/20（血量），受伤倍率0.8/2.8/...，还有什么要增加的],[.....]]；然后传导表用二维数组存好了……如果有更高效的方法，让程序自己想，我们只是给出一个例子；我们后续详细讨论（11-23 08:31）

**解释**：部位用二维数组、传导用二维数组；**具体数据结构程序可以优化**，我们只保证语义（见第二节）。

> 3.移动方式，也就是行为逻辑，后续详细讨论 / 4.攻击方式算到行为逻辑里面 / 5.士气在出怪逻辑里面讨论 / 6.奖励等出怪逻辑想完然后讨论（11-23 08:31）

**解释**：模板只管"这个敌人有什么"；怎么动、怎么打属于行为逻辑（已谈，见第四节）；士气与奖励属于出怪逻辑（**尚未定，先留接口**）。

## 1.4 行为细节

> 2.战船不允许重叠，也就是说敌人想要换航道的时候要先判断是否有人，如果有人就是换航道失败，失败原因为【有人】，记得还要考虑敌人何时会选择换道，最简单的模板可以先不换（11-23 08:42）

**解释**：同航道不重叠；换道前查目标航道是否有人，有人则失败并记录原因 `"有人"`；**首版 `can_change_lane = false`，不启用**。

> 3.敌人打谁，当前这个简单的模板，当玩家在射程内的时候（同一条道路且在攻击范围内），就攻击玩家，当不攻击玩家时，尝试攻击堡垒，如果无法攻击到堡垒，就选择不攻击（11-23 08:42）

**解释**：目标优先级——**同道且玩家在射程 → 打玩家；否则堡在射程 → 打堡；都不满足 → 不开火**。

> 4.敌方船只靠近碉堡后会保持距离持续输出碉堡（11-23 08:42）

**解释**：推进到距堡 `stop_distance` 处停下，原地持续开火；**不撞击、不自毁**。

> 5.敌方船只应该具有玩家船只的基本模块功能，比如后坐力，还有其他几项你列一下，我看看有没有要删除的，比如自动修理不能有（11-23 08:42）

**解释**：敌船要复用玩家船的部分模块，但**删除：弹药、自动维修、升级、船长名**；保留：移动、自动瞄准、开火冷却、部位、传导、后坐力、碰撞箱、接舷（被触发方）。详见 1.5。

> 6.接舷战等敌人模板设计完再说（11-23 08:42）

**解释**：本版本不实现接舷战。

> 1.部位损伤影响敌人的行为这是部位损伤的逻辑，敌人的行为我是在讨论敌人的行为树啊（11-23 08:42）

**解释**：**行为树不判断部位状态**。部位造成的减速、哑火属于部位 debuff，直接改 `speed` 与 `attack_cd`，行为树只读最终值。

## 1.5 敌船模块清单

| 模块 | 敌船 | 说明 |
| --- | --- | --- |
| 航道内移动 | ✅ | 沿航道向左推进 |

| 弹药 | ❌ | 无限弹药，只受间隔限制 |

# 二、敌人模板：数据结构

## 2.1 部位（二维数组）

```text
parts = [
  // [部位ID, 当前血量, 血量上限, [实心倍率, 破帆倍率, 爆炸倍率], 碰撞箱, 状态]
  [ "SAIL",   30, 30, [0.60, 1.80, 0.70], "软", "正常" ],
  [ "HULL",   40, 40, [1.00, 0.25, 0.85], "硬", "正常" ],
  [ "CANNON", 20, 20, [0.85, 0.20, 0.95], "硬", "正常" ],
]
```

- 倍率数组长度**固定 3**，顺序＝实心 / 破帆 / 爆炸
- 状态由 `当前/上限` 实时算出，**不单独存**
- 舵与撞角没有碰撞箱，单独存：

```text
hidden_parts = [
  [ "RUDDER", 10, 10 ],
  [ "RAM",    10, 10 ],
]
```

## 2.2 传导（二维数组）

行＝主命中部位（帆/舰体/炮台），列＝传导目标（舵/撞角），值＝`[概率, 伤害比例]`：

```text
conduction = [
  //              舵              撞角
  [ [0.15, 0.30], [0.10, 0.30] ],   // 命中舰体
  [ [0.10, 0.30], [0.10, 0.30] ],   // 命中炮台
  [ [0.00, 0.00], [0.00, 0.00] ],   // 命中帆：不传导
]
```

## 2.3 其余字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | `E-01`，不复用 |
| `display_name` | String | 倭船 |
| `sprite` / `size` | Path / Vector2 | 1280×720 坐标系 |
| `speed` | float | px/s |
| `stop_distance` | float | 距堡多远停下输出 |
| `min_gap` | float | 同航道最小间距（约 1.2 船身） |
| `can_change_lane` | bool | **默认 false** |
| `lane_change_margin` | float | 换道时判"有人"的 x 阈值 |
| `lane_change_fail_reason` | String | 运行时记录，如 `"有人"` |
| `attack_interval` / `attack_damage` / `attack_range` | float | 开火参数 |
| `morale` / `retreat_threshold` | float | **接口字段**，数值待 M14 |
| `reward_*` | — | **接口字段**，数值待 M14 |

> `behavior` 这个枚举去掉了：行为由行为树决定，不再按类型分派。

# 三、模板敌人：E-01 倭船（完整细节）

## 3.1 身份卡

| 项 | 值 |
| --- | --- |
| ID | `E-01` |
| 名称 | 倭船 |
| 尺寸 | 120 × 56（玩家船约 160×80，它略小） |
| 定位 | 最基础的推进单位，玩家前两场主要打它 |
| 一眼特征 | 慢、血中等、帆最脆 |

## 3.2 部位数值（占位，数值组会改）

| 部位 | 血量 | 实心 | 破帆 | 爆炸 | 碰撞箱 |
| --- | --- | --- | --- | --- | --- |
| 帆 | 30 | 0.60 | **1.80** | 0.70 | 软（穿透） |
| 舰体 | 40 | **1.00** | 0.25 | 0.85 | 硬 |
| 炮台 | 20 | 0.85 | 0.20 | **0.95** | 硬（伴随伤害） |
| 舵 | 10 | — | — | — | 无（传导） |
| 撞角 | 10 | — | — | — | 无（传导） |

**读法**：破帆弹打帆三下大约就能让它降速；实心弹打舰体最有效；爆炸弹对炮台最划算。

## 3.3 行为（行为树）

```
Root（优先级选择，从上往下第一个满足的执行）
1. 舰体归零                → SINK（沉没、移出战场）
2. morale ≤ retreat_threshold → FLEE（掉头向右、离场、不给奖励）
3. 玩家同航道 且 距离 ≤ attack_range → ATTACK_PLAYER
4. 堡在 attack_range 内          → ATTACK_FORTRESS（停在 stop_distance 持续输出）
5. 前方 min_gap 内无同伙         → ADVANCE
6. 其余                         → HOLD（原地等待）
```

- 打玩家时**不前进**；打堡时停在 `stop_distance`
- 不同航道永远不打玩家
- 目标切换加 0.3 s 冷却，避免边缘反复横跳

## 3.4 开火（占位）

| 参数 | 值 |
| --- | --- |
| `attack_interval` | 3.0 s |
| `attack_damage` | 8 |
| `attack_range` | 400 px |
| 弹道 | 与玩家同一套积分器，初速固定，不做提前量 |
| 弹药 | 无限 |
| 炮台被破坏 | **完全停止开火** |

## 3.5 受击

- 子弹命中前先比 `lane_index`，跨道不结算
- 帆：结算后子弹不销毁，继续飞；同一发对同一部位只结算一次
- 舰体：结算后销毁
- 炮台：结算后销毁，并对舰体按系数追加伤害（占位 0.5）
- 部位跨过 0.75 / 0.10 时，debuff 立即生效

## 3.6 士气与奖励（接口，数值待定）

- 有 `morale` 与 `retreat_threshold`，行为树第 2 条读它
- 部位受损、被击沉是否扣士气：**M14 定**，先留监听点
- 沉没时调用 `on_enemy_sunk(enemy)`，奖励内容由外部填
- `FLEE` 离场**不给奖励**

## 3.7 表现需求

| 给谁 | 内容 |
| --- | --- |
| 美术 | 倭船贴图 + 帆/舰体/炮台三种受损外观；沉没动画 |
| 音效 | 开火声（区别于玩家船）、部位被击中的三种反馈、沉没声 |
| 特效 | 帆被破帆弹击中时帆布绞碎；被击沉时木屑与水花 |

# 四、与玩家船的共享规则（并行开发必读）

玩家船由天羽做、敌人由田做，下面六项**必须用同一份实现**，不要各写一套：

| 共享项 | 约定 |
| --- | --- |
| `lane_index` | 同一份航道表；`lane_offset_y` 只做视觉，不改航道 |
| 跨道过滤 | 命中前先比航道；不同道直接穿过 |
| 碰撞箱命名 | `hit_sail` / `hit_hull` / `hit_cannon` |
| 部位枚举 | `SAIL` / `HULL` / `CANNON` / `RUDDER` / `RAM` |
| 弹道积分器 | 同一个函数、同一个 dt；建议天羽写，田调用 |
| 后坐力 | 同一套实现；只做视觉，不改航道 |

> 建议：这六项由天羽先落成公共类/配置，田直接引用。各写一套的话，合并时必然打架。

# 五、验收清单

- [ ] 数据文件能配出 E-01，代码里没有针对它的特判
- [ ] 改 `speed` 立即生效，不用改代码
- [ ] 同航道连续生成 5 艘不重叠，前方有船会减速跟随
- [ ] 推进到 `stop_distance` 停下，持续输出，不撞击
- [ ] 玩家同道进射程 → 转火玩家；换道离开 → 立刻切回打堡
- [ ] 射程外不开火
- [ ] 打帆后炮弹继续飞；跨道飞过不触发任何结算
- [ ] 部位跨过 0.75 / 0.10 时 debuff 立即生效（帆减速、炮台哑火）
- [ ] 打舰体时舵/撞角按概率掉血；打帆时不掉
- [ ] 舰体归零 → 沉没 + 调用奖励接口一次
- [ ] 手动把士气设到阈值下 → 掉头离场且不给奖励
- [ ] 开火有后坐视觉，`lane_index` 全程不变
