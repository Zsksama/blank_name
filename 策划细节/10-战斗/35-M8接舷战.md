# 二、定案：接舷是什么

> **接舷是守卫战的延伸，是玩家"没保持好距离"的惩罚。玩家随时可以主动撞上去——但要不要撞，是你自己按公式算的账，系统不给加成。**

| 项 | 结论 |
| --- | --- |
| 性质 | 被动作战（守卫战延伸） |
| 常态触发 | 敌船贴上来 |
| 主动触发 | **玩家随时可以**主动靠近并撞击 |
| 主动性来源 | **不是系统加成，是玩家的判断**：我方撞角好、对方撞角差时，撞了才划算 |
| 三种结局 | 胜利 / 逃跑 / 失败 |
| 奖励 | **没有**，胜利只有敌船没了 + 气焰跌 |

# 三、触发

## 3.1 两条路

| 路 | 说明 |
| --- | --- |
| **被动** | 敌船贴上来接触 → 进入接舷 |
| **主动** | 玩家自己撞上去——**任何时候都可以**，没有前置条件 |

- 玩家也可以**躲**（唬船高机动）
- 主动撞是否划算，由第四节公式自然决定，**系统不做"优势判定"**

## 3.2 判定门槛（占位）

| 项 | 值 |
| --- | --- |
| 接触 | 碰撞箱相交 或 中心距 ≤ 40 px |
| 最小相对速度 | 80 px/s |
| 进入接舷 | 撞击后仍在接触，且双方都未沉 |

## 3.3 去重

- 同一对船在一次接舷结束后有冷却（占位 3 s）
- **接舷过程中不能反复触发**

## 3.4 换道重叠（11-25 新增）

- 友方换道解禁，可以进入有敌人的水道
- 与敌船重叠 → 触发接舷
- 与"主动撞"等价：**不额外加成**，也不额外惩罚
- **待你确认**：换道重叠算不算"撞击"（要不要走 4.x 的速度计算）

# 四、撞击阶段

## 4.1 伤害公式

```
X 受到的伤害 = 相对速度 × (吨位Y / 吨位X) × 撞角减伤(X) × k
```

- **双方各算一次，各自用自己的撞角减自己的伤**
- 撞角越好 → 自己受的伤越少

## 4.2 撞角减伤（已定口径）

```
撞角减伤 = 撞角剩余耐久比例 × 0.7
```

| 撞角状态 | 剩余比例（按 M4 三档） | 减伤 |
| --- | --- | --- |
| 完好 | 1.0 | 0.70 |
| 破损 | 0.75 以下 | 0.53 以下 |
| 被破坏 | 0.10 以下 | 0.07 以下 |

- 阈值**直接复用 M4**：0.75 / 0.10
- **例**：撞角剩余 90% 耐久 → 减免 `0.9 × 0.7 = 63%` 的伤害（主策划确认）

## 4.3 撞角自身的损耗

- 每次撞击，撞角耐久**减少**，减少量与"这次减免掉的伤害"相关
- **占位：每次损失 0.2**（具体公式交数值组，后续再设计）
- 单次损失上限 0.3（保留）

## 4.4 表现

- 大字「**撞击！**」+ 船体顿挫 + 水花木屑

# 五、接舷阶段

## 5.1 过程

```
镜头放大到双方船只 → 进入暂停模式（见第八节）
  → 双方舰体持续掉血，直到一方达成结局
```

## 5.2 掉血公式

```
我方输出 = 我方战力 × 灯火系数
敌方输出 = 敌方战力 × 气焰系数

每秒：我方舰体 -= 敌方输出 × dt
      敌方舰体 -= 我方输出 × dt
      其余部位 -= 舰体伤害 × 30%
```

## 5.3 气焰系数（已定）

| 气焰状态 | 比例区间 | 系数 |
| --- | --- | --- |
| **嚣张** | > 0.85 | **1.2** |
| **锐挫** | 0.30 — 0.85 | **0.9** |
| **弩末** | 0.10 — 0.30 | **0.75** |
| **穷寇** | < 0.10 | **1.3** |

> **穷寇最凶**：气焰崩到底反而输出最高——走投无路的拼命，也是玩家最该算进去的一段。

- **气焰最低 1%**（撤退也算被击败，可能被扣到 0 以下）
- **特殊敌人**在场时，气焰**始终不低于 0.15**——永远不会进入穷寇撤退（接口，后续设计）

## 5.4 战力

- 独立数值，**不跟舰体血量挂钩**
- 我方：初始 100，可升级
- 敌方：`(单位基础值 + 随机偏移) × 难度系数`

## 5.5 灯火系数

| 灯火 | 系数 |
| --- | --- |
| 渺茫 | 0.9 |
| 温和 | 1.0 |
| 明亮 | 1.1 |

（占位，接 `14` 号）

## 5.6 QTE（已定细则，11-25）

- 接舷开始时，屏幕上**出现文字提示：按空格**
- 倍率 `qte_mult`：**最低 1.0**
- **每 0.3 s 自然衰减 0.01**
- **每次按下空格 +0.01**
- **上限 1.5**（占位）
- 最终并入我方输出：`我方输出 = 战力 × 灯火系数 × qte_mult`

## 5.7 镜头

- 放大到双方船只（相机缩放 + 居中）
- **不切场景**
- 退出后复位

# 七、气焰

## 7.1 命名

**"敌方士气" → 「气焰」**，全项目统一。

## 7.2 状态与系数

- **气焰是全场唯一的一个值**，所有敌人共享同一个状态；**没有「个体气焰」**
- 四档只影响敌方输出系数（见 5.3）；是否影响敌船行为**后续再接**
- 接舷时用它判断当前处于哪一档，不区分是哪一艘船

## 7.3 数值机制（11-25 定）

**本质值**：

```
气焰 = 当前敌人数 / 初始敌人数        # 10/10 = 100%，9/10 = 90%
```

**击沉一艘时不是瞬间掉完，而是分两步**：

| 步骤 | 规则 |
| --- | --- |
| ① 立即扣 | 先立即扣掉「这次该扣的量」的 **0.5 ± 0.1**（随机） |
| ② 缓慢补 | 剩下的部分在约 **2 s** 内缓缓补完 |

> 例：10/10 击沉一艘 → 本质 90%（该扣 10%）。先瞬间扣 4%—6%（到 84%—86%），再缓缓回落到 90%。

**事件加减（接舷胜败等）**：见第十一节——原则是**最终在本质值上做加减**，再夹到 [1%, 100%]。

## 7.4 台词素材

「挫其气焰」「气焰大减」「贼气已夺」「避其锐气，击其惰归」

# 八、时间控制：接舷期间怎么"停"

## 8.1 三种做法

| 方案 | 做法 | 优点 | 风险 |
| --- | --- | --- | --- |
| **A 真暂停** | `Engine.time_scale = 0` | 世界绝对静止 | 每个节点都要指定 `process_mode`（PAUSABLE / ALWAYS），漏一个就出 bug：该停的没停、该动的冻结 |
| **B 减速** | `Engine.time_scale = 0.02—0.08` | **不动 process_mode**，改动面小一个数量级 | 世界仍在极慢地走 |
| **C 双时间** | 世界减速 + 接舷界面走**真实时间** | 演出节奏不受影响 | 要明确哪些系统读哪个时间 |

## 8.2 【建议】B + C

- 接舷开始时 `Engine.time_scale = 0.03`（占位）
- **接舷界面与演出用真实时间**（`Time.get_ticks_msec()`，或把该节点设成 `process_mode = ALWAYS`）
- 否则接舷的动画、镜头过渡、UI 动效会跟着一起变慢
- 真暂停留给后续的"菜单暂停"，那时再逐节点过 `process_mode`

> 这样接舷就**不是"暂停的特殊情况"**，而是一种"时间被压到 3%"的普通状态——正是你提的思路。

## 8.3 接舷期间必须处理的清单

| # | 项 | 处理 |
| --- | --- | --- |
| 1 | 输入 | 进入时清空按键状态；只响应空格 / T |
| 2 | 接触判定 | 接舷期间**禁用再次触发**，否则减速世界里会持续碰撞 |
| 3 | 计时器 | 世界层冷却/维修按减速时间走（可接受）；**接舷自身计时用真实时间** |
| 4 | 空中炮弹 | 继续飞但极慢，接舷结束后自然恢复 |
| 5 | 动画 / Tween / 粒子 | 世界层跟随减速；**演出层不跟随** |
| 6 | 音频 | BGM 继续，音效正常 |
| 7 | 相机 | 缩放过渡用真实时间 |
| 8 | 恢复 | 恢复 `time_scale` → 清输入 → 检查计时器 → 解除去重冷却 |

## 8.4 已定（11-25）

- **方案选 B + C**：`time_scale = 0.03` 减速；接舷演出走真实时间
- 空中炮弹继续飞（减速下几乎不动）
- 接舷结束后敌船**先僵直 0.5 s** 再恢复行为树

# 十三、11-25 收尾：气焰与撤退的准确口径

| 项 | 口径 |
| --- | --- |
| 气焰 | **全场一个值**，所有敌人共享 |
| 气焰条 | **只显示百分比**；`now/max` 是另一个 UI |
| 本质值 | `当前敌人数 / 初始敌人数` |
| 击沉扣减 | 立即扣 `0.5 ± 0.1`，剩余 **2 s** 内缓缓补完 |
| 事件修正 | `morale_bias`，**每场战斗重置**，不跨场累计 |
| 撤退 | **每艘敌船各自在行为树里进入撤退状态**，不是全局脚本统一掉头 |
| 撤退表现 | 敌船贴图**左右镜像**后向画面右侧撤 |
| 被击败判定 | 完全离开画面才计 |
| clamp | 无需纠结两端——低于 0.10 已经在撤了 |
