# 二、定案：接舷是什么

> **接舷是守卫战的延伸，是玩家"没保持好距离"的惩罚；玩家唯一的主动是"趁对方撞角坏了，撞上去"。**

| 项 | 结论 |
| --- | --- |
| 性质 | **被动作战**（守卫战的延伸） |
| 常态触发者 | **敌船**（看各船行为习惯；玩家可躲） |
| 玩家能动性 | ① 高机动躲开 ② 趁敌撞角差时撞上去 |
| 三种结局 | **胜利 / 逃跑 / 失败** |
| **奖励** | **没有**。胜利只有"敌船没了 + 气焰大跌" |

# 三、触发

## 3.1 被动触发（常态）

- 敌船主动贴近并接触 → 进入接舷
- **玩家可以躲**：唬船高机动
- 每类敌船有自己的"贴船倾向"

## 3.2 主动触发（唯一）

```
敌方撞角状态为「破损」或「被破坏」
  → 玩家撞上去 → 撞击造成大量伤害
  → 己方占优 → 主动进入接舷
```

- 不满足条件时撞上去，打不出优势，等于自找吃亏

## 3.3 判定门槛（占位）

| 项 | 值 |
| --- | --- |
| 接触判定 | 碰撞箱相交 或 中心距 ≤ 40 px |
| 撞击最小相对速度 | 80 px/s |
| 进入接舷 | 撞击后仍在接触，且双方都未沉 |

# 四、撞击阶段

## 4.1 伤害公式（已定口径）

```
X 受到的伤害 = 相对速度 × (吨位Y / 吨位X) × 撞角减伤(X) × k
```

**关键：双方各算一次，各自用自己的撞角减自己的伤。**

| 项 | 说明 |
| --- | --- |
| 相对速度 | 接触瞬间两船相对速度 |
| 吨位比 | 大船撞小船伤害高，反之低 |
| **撞角减伤(X)** | **X 自己的撞角状态**：完好 1.0，越破减伤越低（占位 0.4—1.0） |
| k | 全局系数（占位 1.0） |

- 撞角本身也会掉耐久（并入 M8）
- 双方同时受伤，不存在"只撞人的那方不吃亏"

## 4.2 主动撞的加成

- 对方撞角「破损/被破坏」时，撞击伤害 **× 1.5**（占位）
- 撞完若对方未沉 → 直接进入接舷，且**我方起手优势**

## 4.3 表现

- 大字「**撞击！**」+ 船体顿挫 + 水花木屑

# 五、接舷阶段

## 5.1 过程

```
镜头放大到双方船只 → 暂停其它单位（含碉堡炮火）
  → 双方舰体持续掉血，直到一方达成结局
```

## 5.2 掉血公式

```
我方输出 = 我方战力 × 灯火系数 × QTE加成
敌方输出 = 敌方战力 × 气焰系数

每秒：我方舰体 -= 敌方输出 × dt
      敌方舰体 -= 我方输出 × dt
      其余部位 -= 舰体伤害 × 比例（占位 30%）
```

| 项 | 口径 |
| --- | --- |
| 我方战力 | 独立数值，可升级（初始 100 占位） |
| 敌方战力 | `(单位基础值 + 随机偏移) × 难度系数` |
| **气焰** | 原"敌士气"，初始 100。`气焰系数 = 0.7 + 气焰/100 × 0.6`（占位） |
| **灯火系数** | 渺茫 0.9 / 温和 1.0 / 明亮 1.1（占位，接 `14`） |
| QTE 加成 | 狂按空格累积，上限 +50%（占位） |
| **其他部位掉血** | **按舰体伤害的比例**（占位 30%），三档与传导规则不变 |

> 只有"舰体归零"才等于沉没；帆/炮台的损坏只影响状态与战力修正。

## 5.3 镜头

- 放大到双方船只：相机缩放 + 居中两船中点
- **不切场景**
- 退出后镜头复位（短过渡）

## 5.4 QTE 与操作

| 操作 | 效果 |
| --- | --- |
| 狂按 **空格** | 加快削减敌方舰体（有上限） |
| 长按 **T** | 「落荒而逃」放弃接舷 |
| 其余 | 冻结 |

## 5.5 起手优势

- 主动撞且对方撞角破损 → 接舷开始时对方舰体先受一次额外伤害（占位 10%）
- 被贴的一方没有

# 六、三种结局

| 结局 | 条件 | 结果 |
| --- | --- | --- |
| **胜利** | 敌方舰体归零 | 击毁敌船 + **气焰大幅下降**（占位 −25）。**没有战利品** |
| **逃跑** | 长按 T 成功 | 向左撤退（占位 200 px）+ 各部位再掉 15% + **气焰上升**（占位 +10） |
| **失败** | 我方舰体归零 | **直接算船被击沉**：扣灯火、下一场从水门再出 |

- 逃跑需**长按约 1.5 s**，中途再受伤则中断
- 逃跑后敌方照旧追（行为树本来就追，**不需要额外机制**）

# 七、气焰（原敌士气）

## 7.1 改名

**"敌方士气" → 「气焰」**，全项目统一。旧文档里的"士气"一律按气焰理解。

## 7.2 状态分档（已定：四档，**暂时仅显示**）

| 气焰比例 | 状态 | 含义 | 倾向 |
| --- | --- | --- | --- |
| **> 0.85** | **嚣张** | 气焰最盛 | 更敢贴、输出更高 |
| **0.30 — 0.85** | **锐挫** | 锐气受挫 | 常态 |
| **0.10 — 0.30** | **弩末** | 强弩之末 | 想撤，输出下滑 |
| **< 0.10** | **穷寇** | 走投无路 | 可能拼命，也可能溃散 |

- 阈值按比例：**0.85 / 0.30 / 0.10**
- ⚠️ **四档暂时只是显示，不接任何行为**。后续可能和**敌船移速**、其他行为与公式挂钩
- 「避其锐气，击其惰归」正好对应 **锐挫 → 弩末** 这一段

## 7.3 气焰总量按「敌人数量」算（11-24 新增）

- **敌人被击沉也会消减气焰**
- 总量按敌人数量计，HUD 显示形如 **14 / 14**（当前剩余 / 最大）
- 每艘敌船仍保留自己的气焰（用于四档显示与接舷计算），总量是它们的聚合
- 口径待定：总量 = **剩余敌船数**，还是 = **剩余各船气焰之和**（见第十节）

## 7.4 台词素材（配音用）

「挫其气焰」「气焰大减」「贼气已夺」「避其锐气，击其惰归」
