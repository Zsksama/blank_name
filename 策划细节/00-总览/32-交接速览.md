## 四、协作约定（压缩后最容易丢的就是这些）

| 约定 | 内容 |
| --- | --- |
| **原话优先** | 每份设计文档第一节是主策划原话，一字未改；整理部分有出入以原话为准 |
| **只加不减** | 整理/重构时不删内容；废弃的标"归档/废弃"，不删除 |
| **编号固定** | 编号是文档 ID（如 23、27），目录结构调整不改编号 |
| **任务卡五段式** | 目标 / 规则 / 边界 / 验收 / 依赖，缺一段退回重写；不许写一行表格 |
| **任务卡私发** | 不进仓库，主策划直接发给程序 |
| **看板不用** | `程序任务派发/任务看板.md` 与 `回传清单.md` 已不维护 |
| **工作目录不发布** | `.local策划文件夹/程序任务派发`、`文化考据组`、`数值设计组` 不进仓库 |
| **数据安全** | 不要点 GitHub Desktop 的 "Discard all changes"；收工跑 `备份策划.bat` |

## 五、关键参数（已定的硬数字）

| 项 | 值 |
| --- | --- |
| 画布 | 1280 × 720 |
| 航道 | Y 轴不连续，逻辑 `lane_index`；`lane_offset_y` 只做视觉 |
| 炮台 | 首版 2 门，0—180° 统一旋转，不能向下；装填 5 s（占位） |
| 弹药 | 三种独立计数、无上限；打几发扣几发；换弹有延迟 |
| 部位 | 3 碰撞箱（帆软 / 舰体硬 / 炮台硬）；舵与撞角靠传导 |
| 三档阈值 | 0.75 / 0.10 |
| 玩家船 | 唬船，部位血量可升级 |
| 敌人 | E-01 倭船：帆 30 / 舰体 40 / 炮台 20（占位） |
| 失败 | 碉堡彻底破坏 + 兜底次数归零 → 回档或进结局 |
