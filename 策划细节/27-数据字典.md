# 27 · 数据字典（T-111 展开）

> 对应任务卡 **T-111 数据层：全部属性 `@export` + 存档**。
> 本文列出**具体有哪些数据项**：字段名、类型、默认值、谁负责填、是否进存档。
> 「归属」一列：**设计**＝已定；**数值**＝数值对话定；**程序**＝运行时/内部。

---

## 一、玩家船 P-01（唬船）

### 1.1 位置与移动

| 字段 | 类型 | 默认 | 归属 | 存档 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `lane_index` | int | 1 | 程序 | 是 | 逻辑航道号，换道才变 |
| `lane_offset_y` | float | 0 | 程序 | 否 | 后坐/浪造成的视觉下沉，**不改 lane_index** |
| `move_speed` | float | 数值 | 数值 | 是 | px/s |
| `lane_switch_time` | float | 0.6 | 数值 | 否 | 换道耗时（过闸），建议做成升级项 |
| `is_switching` | bool | false | 程序 | 否 | 换道期间禁止开火 |

### 1.2 部位（5 个，固定顺序）

部位枚举：`HULL` 舰体 / `SAIL` 帆 / `CANNON` 炮台 / `RUDDER` 舵 / `RAM` 撞角

| 字段 | 类型 | 默认 | 归属 | 存档 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `part_hp_max[5]` | PackedFloat32Array | 数值 | 数值 | 是 | **绝对值，可升级** |
| `part_hp[5]` | PackedFloat32Array | = max | 程序 | 是 | 当前血量 |
| `threshold_broken` | float | 0.75 | 数值 | 否 | 降到该比例以下＝破损 |
| `threshold_destroyed` | float | 0.10 | 数值 | 否 | 降到该比例以下＝被破坏 |
| `part_state[5]` | int（派生） | — | 程序 | 否 | 由 hp/max 计算，**不单独存** |

> 只有 HULL 归零才沉没；其余部位被破坏只降效率（已定）。

### 1.3 炮台（首版 2 门，列表结构）

| 字段 | 类型 | 默认 | 归属 | 存档 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `turret_count` | int | 2 | 设计 | 是 | 可升级增加 |
| `turret_angle[ ]` | PackedFloat32Array | 0 | 程序 | 否 | 当前角度（多炮统一旋转） |
| `turret_angle_min` | float | 0 | 设计 | 否 | 0°＝正前 |
| `turret_angle_max` | float | 180 | 设计 | 否 | 180°＝正后；不能向下 |
| `turret_angle_speed` | float | 数值 | 数值 | 是 | 跟随鼠标的角速度 deg/s（等级影响） |
| `turret_reload_time[ ]` | PackedFloat32Array | 5.0 | 数值 | 是 | 每门炮装填秒数 |
| `turret_reload_left[ ]` | PackedFloat32Array | 0 | 程序 | 否 | 剩余冷却，UI 画分段圆环用 |
| `turret_damage_mult[ ]` | PackedFloat32Array | 1.0 | 数值 | 是 | 升级加成 |

### 1.4 弹药与发射

| 字段 | 类型 | 默认 | 归属 | 存档 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `ammo[3]` | PackedInt32Array | 0 | 程序 | 是 | 实心 / 破帆 / 爆炸，**各自独立、无上限** |
| `ammo_selected` | int | 0 | 程序 | 是 | 当前选中弹种 |
| `fire_mode` | int | 0 | 程序 | 是 | 0＝单发，1＝齐射 |
| `switch_ammo_delay` | float | 1.5 | 数值 | 否 | 换弹惩罚，期间不能开火 |
| `savage_spread_deg` | float | 5.0 | 数值 | 否 | 齐射散布（单侧角度） |

### 1.5 自动维修（M6）

| 字段 | 类型 | 默认 | 归属 | 存档 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `repair_base_rate` | float | 0.5 | 数值 | 否 | 每秒回复百分比 |
| `repair_discount_broken` | float | 1.0 | 数值 | 否 | 破损状态速率折扣 |
| `repair_discount_destroyed` | float | 0.2 | 数值 | 否 | 被破坏状态速率折扣 |
| `max_repair_ratio` | float | 0.6 | 数值 | 是 | 最大可维修度（**可升级**） |

### 1.6 后坐力（M2）

| 字段 | 类型 | 默认 | 归属 | 存档 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `recoil_impulse` | float | 0 | 数值 | 否 | 水平后移量 px |
| `recoil_sink` | float | 0 | 数值 | 否 | 竖直下沉 px（真 y，但不改航道） |
| `recoil_pitch` | float | 0 | 数值 | 否 | 船头翘起角度 |
| `recoil_recover_time` | float | 0.15 | 数值 | 否 | 回弹时间 |

### 1.7 击沉与复活

| 字段 | 类型 | 默认 | 归属 | 存档 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `is_sunk` | bool | false | 程序 | 否 | |
| `respawn_timer` | float | 数值 | 数值 | 否 | 复活倒计时 |
| `captain_name` | String | 空 | 设计 | 是 | 船长名（史料/虚构待定） |

## 四、跨场景与存档（MetaState，**必须存档**）

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `save_version` | int | 1 | 存档格式版本，升级时用 |
| `day` | int | 1 | 日历 |
| `difficulty` | int | 1 | 0 简单 / 1 普通 / 2 困难 |
| `materials` | int | 0 | 材料 |
| `research` | int | 0 | 研究点（暂名） |
| `lamp_value` | float | 50 | 灯火 0—100 |
| `lamp_level` | int（派生） | 1 | 渺茫 / 温和 / 明亮 |
| `upgrades` | Dictionary | {} | `{升级ID: 等级}`，如 `{"U-01":2}` |
| `ship_part_hp[5]` | PackedFloat32Array | 满 | 战船部位当前血量 |
| `ship_part_hp_max[5]` | PackedFloat32Array | 数值 | 部位上限（升级后变） |
| `ammo[3]` | PackedInt32Array | 0 | 三种弹药库存 |
| `fort_hp` | float | 数值 | 堡耐久 |
| `fail_times` | int | 0 | 已失败次数 |
| `ending_id` | int | -1 | 结局标记（-1 未结算） |

> **不存的**：子弹、冷却进度、后坐力偏移、飘字、特效、换道中间态。重开一场时全部重置。

## 六、验收标准

- [ ] 上面所有「数值」列归属的字段，在 Godot 检查器里可改（`@export`）
- [ ] 存档保存后重开游戏，MetaState 所有字段一致（往返一致）
- [ ] 战斗结束进经营、经营结束回战斗，数值不丢
- [ ] 缺少字段时用默认值兜底，不崩
- [ ] `part_state` 由 hp/max 实时算出，不单独存（避免不一致）
- [ ] 子弹与冷却这类临时值不进存档

---

## 七、给 T-111 的补充说明

1. **先做 MetaState 与 P-01 两组**，其余（敌方、经营）等对应模块定了再加
2. 存档用 JSON 或 Godot `Resource` 都行，但**必须带 `save_version`**，否则以后加字段会读不了旧档
3. 调试面板要能直接改 `materials / research / lamp_value / ammo[]`，调数值靠它
