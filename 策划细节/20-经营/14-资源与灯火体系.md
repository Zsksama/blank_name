## 一、材料

```
木材 ┐
     ├─→  材料（固定产出 + 民船经营）
石材 ┘
```

- **木材与石材合并为一种「材料」**
- 来源：**固定产出** + **民船经营**
- 去向：**军事战斗**、**升级**

> 17:03 确认：民船经营是**自动产出**，算在常规经营策略里面（不需要玩家手动派船）。

## 二、军事战斗 → 弹药

```
材料 → 军事战斗 → 弹药量 / 新品种
```

弹药的数量与种类都由材料支撑；对应界面上那三个弹药位。

## 三、升级

| 升级对象 | 备注 |
| --- | --- |
| 战船 | 对应顶部 `船Ⅲ` |
| 碉堡炮台 | 对应顶部 `堡Ⅲ` |

升级的两个二级效果：

- **弹药耗材减少**
- **预警机制**（17:03 说明，见第六节）

## 四、灯火（已确认为三档）

- 定位：**视灯火为一个状态**，不是资源
- **档位：三档，简单一点**；草图里写的 `欢乐 / 安稳 / 正常 / 波动 / 战乱` 五档，作为命名素材保留
- 灯火不同状态会**产出不同量的资源**
- 这个资源与灯火相关，名字还没想好，**暂名「研究点」**，用于升级

> 所以灯火是一个"越亮越能干"的状态：它不直接花，但它决定你每轮能拿到多少研究点。

## 八、民众的意愿

> 民众会根据自己的状态，给出选项的意愿，有不同的加成。

链条：灯火状态 → 民众意愿 → 罗盘最上方那项 → 加成更好。

## 九、循环（按草图连起来）

```
固定产出 + 民船经营（自动） ──→ 材料 ──┬──→ 弹药（数量/新品种）──→ 战斗
                                     └──→ 升级（战船/碉堡炮台/材料产出）
                                                                  │
战斗结果 ──→ 船毁、堡血掉到阈值 ──→ 灯火度下降 ──┬──→ 研究点产出减少 ──→ 升级变慢
                                              └──→ 民众意愿变差 ──→ 选项加成变差

升级 ──→ 弹药耗材减少、预警机制
失败：碉堡彻底破坏 + 兜底次数归零 → 回档
```

一句话：**材料决定你能打多少，灯火决定你能变成什么；而灯火是打出来的。**
