# 18 · 命名提案

> 只列候选与评价，不替你定。选定后建议查一遍重名（Steam / itch / TapTap / B 站）。

---

## 一、游戏名

| 候选 | 扣什么 | 优点 | 弱点 |
| --- | --- | --- | --- |
| **《哨船》** | 玩家船的真实船型（明代"福船之小者"），哨＝瞭望 | 短、独特、直接指玩家身份；玩法与名字一致 | 两个字略冷，不懂"哨船"的人第一眼不知道是什么 |
| **《一夜水门》** | 单夜循环 + 永昌堡水门 | 有画面、有事件感，适合视频标题 | 四个字，"一夜"会让人以为是恐怖游戏 |
| **《灯火长明》** | 理想结局名 | 情绪最强，最容易被记住、被引用 | 与玩法关联弱，容易像解谜或视觉小说 |
| **《鸣金》** | 游戏内结束经营的动作 | 短促有节奏，气质硬 | 语义偏"收兵"，可能被理解成撤退游戏 |
| **《水门》** | 地标 | 干净、有画面 | 与"水门事件"撞联想；搜索不友好 |
| **《守望水门》** | 主题 + 地标 | 最直白扣题 | "守望"太通用，独特性差 |
| **《望海》** | 主题的"望" | 两字干净，与海防贴合 | 偏文艺，看不出是塔防 |
| **《铜锣与灯火》** | 两个核心意象 | 画面感强，适合做副标题 | 太长，做主标题弱 |

**我的评价**（不是结论）：
- 想**独特 + 与玩法一致** → 《哨船》
- 想**传播 + 情绪** → 《灯火长明》
- 想**干净 + 有地气** → 《水门》

外语名建议同时定一个：`Sentry Boat` / `The Water Gate` / `Lanterns Stay Lit`。

## 二、系统与资源命名

### "研究点"（暂名）候选

| 候选 | 语感 | 评价 |
| --- | --- | --- |
| 匠作 | 明代匠籍、匠作监 | 古味最正，与"升级营造"贴合 |
| 营造 | 建筑学 | 偏建筑，涵盖不了战船升级 |
| 工造 | 通用 | 中性、好懂 |
| 图纸 | 具象 | 直观，但和"点数"的抽象感不合 |
| 军械 | 军事 | 只能覆盖武器，覆盖不了城镇 |
| **研究点** | 现代表述 | 最好懂，但出戏；可作内测称呼 |

### 弹药三种（建议方向，待你定）

- 实心弹 / 散弹 / 火油弹
- 或按明代军械：铁弹 / 子母弹 / 火砖

### 发射方式两种

- 单发 / 齐射
- 或 直射 / 抛射（更贴古代火炮的实际用法）

### 灯火三档

- 你已定：**渺茫 / 温和 / 明亮**
- 备选（更文一点）：微茫 / 温煦 / 昭明

### 难度名

- 你提过"困难（或者称为当年）"——"当年"这个词很好，建议做成一组：
  **平年 / 凶年 / 当年**（"当年"= 那一年真出事了）

### 事件名（常规经营）

- 你给的：积极备战 / 大力经营 / 平安度日
- 备选：**厉兵 / 通商 / 安澜**（更文，但不够口语）

## 三、船长名

- 真实人名（王沛、王德、汤和、王叔果、王叔杲）**不建议**直接当可阵亡的船长，见 `17-文化考据.md` 第五节
- 建议：**虚构船长名** + 阵亡名单里致敬真实人名
- 虚构方向：取明代沿海常见姓（王、陈、林、叶、张）配单字或排行，如"陈十三""叶阿六"，比"李将军"更贴水乡
