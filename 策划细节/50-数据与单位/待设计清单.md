## 一、战斗 · 武器与弹道

### N-01 三种弹药的伤害与部位倍率

- **要定**：实心弹 / 破帆弹 / 爆炸弹的基础伤害，以及对帆、舰体、火器与弓手三个部位的倍率
- **背景**：M3 定案三弹各有定位——实心打舰体、破帆专撕帆、爆炸清群。倍率若拉不开，三种弹就退化成"伤害不同的同一种弹"，弹药切换失去意义
- **当前占位**：实心 12（帆 0.6 / 舰体 1.0 / 炮台 0.85）；破帆 5（帆 1.8 / 舰体 0.25 / 炮台 0.2）；爆炸 8 中心 → 4 边缘
- **依赖**：M4 部位血量（N-07）

### N-02 弹道参数：初速、重力、阻力系数

- **要定**：三种弹各自的初速；全局重力；阻力系数 `drag_k`
- **背景**：M2 定为实时抛物线 + 数值积分，预览线与实战共用同一套积分器。阻力系数设 0 就是纯抛物线，越大越"真实"；它会明显改变竖直射高，是手感的核心旋钮
- **当前占位**：实心 520 / 破帆 680 / 爆炸 420 px/s；重力待定；`drag_k` 默认 0
- **依赖**：M2 弹道实现

### N-03 装填时间（2 门炮）

- **要定**：每门炮装填一次要多久
- **背景**：M2 已定"每门炮独立冷却 + 圆环分两段显示"，开火要谨慎；装填时间直接决定单场节奏（现在 5 s 是占位）
- **当前占位**：5 s
- **依赖**：无，但要与敌方血量一起调

### N-04 换弹延迟

- **要定**：切换弹药时要多久不能开火
- **背景**：M3 已定"换弹惩罚必须有"，否则玩家可以在两发之间随意切弹，三种弹的取舍消失
- **当前占位**：1.5 s
- **依赖**：M3

### N-05 齐射散布角

- **要定**：齐射时各炮的夹角
- **背景**：M2 定齐射为"所有就绪炮统一开火，打几发扣几发"；散布决定它更适合打面还是打点
- **当前占位**：±5°
- **依赖**：M2

### N-06 后坐力参数

- **要定**：水平后移量、竖直下沉量、回弹速度
- **背景**：M2 定后坐力全部由代码实现（不需要美术画），且下沉用真实 y 但不改航道。史料里有"发熕放时船震动而倒缩"可作风格依据
- **当前占位**：全部 0（纯动画），测的时候再调
- **依赖**：M2

## 二、战斗 · 部位与舰船

### N-07 各部位血量与三档阈值

- **要定**：帆 / 舰体 / 火器与弓手 / 舵 / 撞角的基础血量；破损与破坏的分界（现 0.75 / 0.1 是否保留）
- **背景**：M4 定三档状态驱动 debuff，血量是绝对值且可升级。阈值若太松，玩家感觉不到"打坏了"
- **当前占位**：阈值 0.75 / 0.1；血量未定
- **依赖**：M4

### N-08 各档 debuff 强度

- **要定**：帆（移速/换道延迟）、炮台（装填/伤害）、舵（换道）、撞角（撞击）在破损与被破坏两档的具体数值
- **背景**：M4 给过参考表（帆 −30% / −60% 等），需按实测调
- **当前占位**：见 `23-M4部位损伤.md` 第五节
- **依赖**：N-07

### N-09 传导概率与伤害比例

- **要定**：命中舰体/火器与弓手时，传导给舵、撞角的概率与比例
- **背景**：M4 定舵与撞角不设碰撞箱，只靠传导受伤；且它们损坏**不致命**，只降效率
- **当前占位**：舰体→舵 15%、撞角 10%；炮台→舵/撞角各 10%；传导伤害 30%
- **依赖**：M4

### N-10 敌方单位数值

- **要定**：倭船 / 快船 / 大船 / 布雷船的血量、速度、伤害、士气影响
- **背景**：敌方士气是胜利条件（不必全歼）；士气跌到阈值即撤退
- **依赖**：敌方单位模块（未开始）

### N-11 大船的部位构成

- **要定**：大船几套帆、几套炮、总血量倍率
- **背景**：M4 定大船用"多部位"而非单纯高血量
- **依赖**：敌方单位模块

## 三、经营与全局

### N-12 资源产出与价格

- **要定**：材料、研究点、弹药的每回合产出；升级、修理、建造成本
- **背景**：经营的核心是"永远差一点"——四天下来不能全升满
- **依赖**：经营模块

### N-13 灯火三档的产出修正

- **要定**：渺茫 / 温和 / 明亮三档对材料、研究点产出的修正比例
- **背景**：灯火是状态不是资源，它决定"每轮能拿到多少"
- **依赖**：经营模块

### N-14 失败次数与难度

- **要定**：简单 3 / 普通 2 / 困难 1 次是否沿用；爆炸弹自伤在简单档关闭、普通困难开启
- **背景**：兜底机制同时服务结局判定
- **依赖**：经营/结局模块

### N-15 升级曲线

- **要定**：炮位数（首版 2 门 → 可升级）、装填速度、初速、部位血量的升级增量与价格
- **背景**：M5 本期只做接口，具体在经营升级模块设计
- **依赖**：经营升级模块

### N-16 自动维修参数

- **要定**：每部位基础自修速率、破损/被破坏状态的速率折扣、"最大可维修度"的最终值
- **背景**：M6 的核心是"战斗内只能止血、必须回港大修"。当前最大可维修度 60% 低于三档阈值 75%，所以战斗中永远修不回"正常"档——这个 60% 是**主策划认可的占位值**，不是结论
- **当前占位**：基数 0.5%/s、破损 ×1、被破坏 ×0.2、上限 60%
- **依赖**：M4 部位血量（N-07）

## 四、接手须知

1. 表里凡写"占位"的，都是**主策划为了先跑起来填的**，不是结论
2. 改任何一项之前，先看它的「背景」——数值是为体验服务的，不是为好看
3. 定完一项就在本清单打勾，并写进 `单系统/` 里的对应表
4. 发现设计层面矛盾（例如某个倍率无论怎么调都不合理），写进回传，不要自己改玩法

# 八、11-28 新增（战斗平衡，数值对话开工用）

> 来源：11-28 主策划验收 + 明确要求「这些记录好后准备让数值处理对话安排」。

### N-41 撤退过程中的持续掉血（**11-28 移交田：这是机制，不是数值**）

- **归属变更**：**不进本轮数值设计**，由田（程序）实现
- **主策划意图**：「破帆敌人撤退太慢，等得太久，我想不要等太久，**让他掉血自己沉没早点结束**」
- **要定（田）**：按什么速率掉、掉到沉没还是到某阈值就撤、是否所有撤退船都掉
- **数值组只给**：一个"希望多少秒内结束"的参考（主策划未定）
- **依赖**：M4 帆损与航速、M13 撤退

### N-42 破帆弹与爆炸弹的强度

- **要定**：破帆弹对帆的伤害倍率；爆炸弹的整体伤害上调幅度
- **背景**：11-28 主策划——"**破帆弹的作用不够明显，爆炸弹也是**"；并且明确一条硬指标：**对重船，破帆弹要一发破帆**
- **当前占位**：破帆弹 5（帆 1.8 / 舰体 0.25 / 火器 0.2）；爆炸弹 8 中心 → 4 边缘
- **依赖**：N-07 各部位血量（尤其重船的帆血量）

### N-43 关卡正式数值

- **要定**：五关的预算、允许池、必出项、阵型池、每关只数
- **背景**：11-28 定：**关卡正式数值移交数值设计专门做**，不再由我拍占位数
- **当前占位**：30 / 45 / 55 / 70 / 90（见 `37` §13），只数 ~10/11/13/12/15
- **依赖**：N-01 弹药、N-10 敌方单位、N-38/N-39 远程

### N-44 双方射程调整（当前过于简单）

- **要定**：**敌人射程上调** 还是 **友方射程下调**，幅度多少
- **背景**：11-28 主策划——"后续考虑数值的时候，可能要增加敌人射程或者减少友方射程，**当前过于简单**"
- **当前**：友方靠初速 640/680/620 决定射程；敌方箭矢 200、火铳 300、堡 400
- **依赖**：N-02 弹道参数（射程由初速+重力算出来，不能直接填射程）
