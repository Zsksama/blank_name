## 三、几条约定

1. **原话优先**：每份文档第一节是主策划原话，整理部分若有出入，以原话为准
2. **只加不减**：整理文档时不删减原内容；废弃的内容标"废弃/归档"，不删除
3. **编号固定**：编号是 ID，不因目录调整而改变
4. **任务卡单独发**：程序任务不在这批文档里，由主策划直接发
5. 使用 AI 生成内容须记录进《AI 使用与素材声明》
