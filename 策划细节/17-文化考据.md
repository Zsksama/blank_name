## 一、永昌堡

| 项 | 内容 | 来源 |
| --- | --- | --- |
| 始建 | **明嘉靖三十七年（1558）**，王叔果、王叔杲等倡议兴筑，以防倭患，历时约一年建成 | [华夏文化遗产基金会](https://www.cchfound.com/product/3374.html) |
| 缘起 | 嘉靖年间倭寇劫掠乡邦，英桥王氏王沛、王德叔侄相继死难；后由王叔果、王叔杲兄弟相地筑堡 | 温州文旅/搜狐文 |
| 形制 | 长方形，南北约 738—778 m，东西约 445—455 m，周长 2366—2688 m（**来源不一**） | 同上 |
| 墙高 | 约 8 m（一说约 5.6 m） | 温州博物馆 |
| 城门 | **陆门 4 座、水门 4 座**，城内引渠贯通 | 同上 |
| 城防 | 敌台 12 座；城堞 605 个（一说 908 个） | 温州博物馆 |
| 地位 | 我国**唯一一座民间私家筹资修建的明代抗倭城堡**；全国重点文物保护单位 | 搜狐/百科 |
| 文化层 | 抗倭、宗族、耕读、古民居、非遗，合为综合性文化基地 | 浙江省政务附件 |

### 英桥王氏

- **耕读传家**：道光三百年间出进士 13 人、武状元 1 人、传胪 1 人
- 设**义田奖学**，为贫困学子提供物资保障
- 存《王氏家录》《王氏世录》《英桥王氏族谱》
- 2019 年 7 月在永昌堡设**英桥王氏家风家训馆**，是温州首家家风家训馆
- 来源：[浙江省政务 PDF](http://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web2149/site/attach/0/bc853740764d412ca385d089d00350a4.pdf)、[永昌堡志 PDF](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web2149/site/attach/0/8bed359eb01348cdaec5e879985e04c9.pdf)

## 二、汤和与汤和信俗

| 项 | 内容 |
| --- | --- |
| 人物 | 汤和，明初信国公，洪武年间经略东南海防 |
| 工程 | 洪武二十年（1387）前后，在浙东浙西沿海**筑卫所城 59 座**，史称"海上长城" |
| 温州布防 | 在温州卫、平阳所基础上，增设**金乡卫、磐石卫**，及瑞安所、海安所、沙园所、**宁村所**、蒲门所、壮士所、蒲岐所等 |
| 宁村所 | 洪武二十年奏请兴建，**隔江与乐清磐石卫相互策应，为入温水路要冲** |
| 信俗 | **2008 年列入第二批国家级非物质文化遗产**；每年**农历七月十五（中元节）**，宁村百姓自发巡游，队伍**从宁村东门出发** |
| 规模 | 温州地区最具规模、持续时间最长的民俗节日之一；中元节习俗中最特殊、最典型的个案之一 |
| 纪年 | 2026 年 8 月 27 日（农历七月十五）为**汤和诞辰 700 周年**巡游 |

来源：[温州网](https://culture.66wz.com/system/2021/10/14/105410307.shtml)、[温州文旅](https://wzstb.wenzhou.gov.cn/art/2013/7/24/art_1217790_1557920.html)、[智慧温州](https://zhihui.66wz.com/system/2026/08/25/105827420.shtml)、[人民图片](http://vip.people.com.cn/albumsDetail?aid=1836724&pid=13489114)

> **对游戏最有用的一句**：宁村所是"入温水路要冲"——我们做水门、航道、要塞，是踩在真实地理上的。

## 三、明代抗倭战船（可直接用作船型名）

据《筹海图编》《武备志》一路记载：

| 船型 | 记载要点 | 游戏里可以是什么 |
| --- | --- | --- |
| **福船** | 福建船六号之一二号，势力雄大，海战利器 | 敌方大船 / 旗舰 |
| **哨船** | "福船之小者……今名哨船"，三号船；广志云"多置哨船，远出外洋分头哨探" | **玩家船**（哨探、轻快） |
| **苍山船** | 首尾皆阔，帆橹并用 | 中型敌船 |
| **沙船** | 底平，宜北洋浅水，可接战但无翼蔽 | 商船 / 民船 |
| **网梭船** | 形如梭，竹桅布帆，仅容二三人，可哨探 | 小船 / 侦察船 |
| **蜈蚣船、鹰船、冬船、鸟船、快船** | 各有用途 | 敌船变体 |

来源：[维基文库·明史卷92](https://zh.wikisource.org/w/index.php?title=%E6%98%8E%E5%8F%B2/%E5%8D%B792&variant=zh-hans)、[识典古籍·海防纂要](https://www.shidianguji.com/zh/book/NA04557/chapter/1ktc5u1efjd48)、[广东通志](https://zh.wikisource.org/zh/%E5%BB%A3%E6%9D%B1%E9%80%9A%E5%BF%97_(%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC)/%E5%85%A8%E8%A6%BD1)

## 四、可直接用的文化元素清单

### 空间与建筑
- **水门**（4 座）、陆门（4 座）、城内引渠、敌台（12 座）、城堞、护城河
- 礁石、滩涂、渡口、码头、吊货架、木桩

### 器物与声响
- **铜锣**、**号角**、**梆子**（更夫）、灯笼、旗（令旗/信旗）、狼烟
- 炮：碗口铳、佛郎机、虎蹲炮（可作为"炮台升级"的名字梯度）

### 民俗与节令
- **七月十五汤和信俗巡游**（宁村东门出发）
- 中元节、元宵灯、清明、冬至
- 抬神像、仪仗、鼓吹、**跑旱船**（民俗表演，正好呼应你草图里那个我读不准的词）

### 人与称谓
- 真实人物：汤和（信国公）、王沛、王德、王叔果、王叔杲
- 制度称谓：卫、所、千户、百户、烽堠、墩台、哨官、哨总

### 家风与文教
- "十三进士"、耕读传家、义田奖学、家训
- 可作为"学堂/文教"升级线的文案素材

## 五、使用时要注意

1. **数字别写死**：墙高、周长、城堞数在来源之间不一致（5.6 m vs 8 m、605 vs 908），游戏里若要写，注明"据地方志/博物馆资料"。
2. **真实人名慎用**：王沛、王德是死难的抗倭义士，汤和是受祀的神明级人物。拿他们当"可阵亡的船长"容易不敬。建议：
   - 玩家船长的名字**用虚构的**，但在阵亡名单 / 结局画面里致敬真实人名
   - 或从族谱里取**真实的常见字号**做虚构角色
3. **汤和信俗是活着的民俗**，不是布景。做巡游相关表现时，最好体现"人参与"而不是"NPC 站桩"。
4. 若用到实景照片/纹样，按 `07-素材与授权.md` 处理授权。
