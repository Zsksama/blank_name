## 三、左栏：事件、司南与资源预览

### 事件列表

- 标题 `显示 N 个事件`，`↑↓ 切换事件`
- **N 个事件＝固定事件 + 特殊随机事件**
  - 固定事件包括：**常规经营**界面、**升级**界面、**修复船只与碉堡**界面
  - 另有**特殊随机事件**界面
- 每个界面下方的方向名随之变化（常规经营里是"大力经营 / 备战 / 正常"这一类）

### 司南（核心交互）

- **司南会始终指向"你当前选中的选项"**
- 两种选中方式，二者等价：
  1. **点击选项条** → 司南转过去指向它
  2. **拖动司南** → 指向哪个选项就选中哪个
- 司南下方显示该选项的资源大致变化，写法如：`材料+++`、`灯火+`

### 介绍

- 左下角按钮，应为当前事件/方向的说明

## 四、中部主区

| 区域 | 内容 |
| --- | --- |
| 上部分 | **剧情** |
| 下部分 | **选项条**：常规游戏式三选一或几选一 |
| 选项条右侧 | 可**跟随具体措施**的文字，用来增加生活气息与写实性 |
| 底部空白 | 放小动画之类，展示生活气息 |

**选项条是长条**，不是因为选项多，而是每条后面能挂"具体措施"——让玩家看到"这一项会让日子变成什么样"。

## 六、常规经营的特别设定（16:52 新增）

> 在常规经营界面里，**罗盘最上方的那一项，是由灯火状态决定的"民众的意愿"**。
> 如果选这一项，会有**比平常更好的加成**。

这条很关键：它让"灯火"从装饰变成一个会反过来影响选择的变量——民心和你的行动方向绑在一起了。

## 七、交互流程

```
进入经营（事件列表默认停在"常规经营"）
  → ↑↓ 切换事件（常规 / 升级 / 修复 / 随机事件）
  → 读上部剧情
  → 在下部选项条里选一项（点击，或拖动司南去指）
  → 司南指向该项，左侧显示材料+++ 灯火+ 之类的预览
  → 确认（待确认是点击即生效还是另有确认键）
  → 可继续切别的界面，或
  → 鸣金：结束经营，等待来敌
```
