## 待办

### T-001 战斗场景骨架：航道 + 碉堡 + 船能换道

- 目标：能进入战斗画面，看到左侧碉堡、三条航道（数量待定，先用 3），船能在航道间移动
- 依据：16 号文档 1.1—1.4；01 号文档第二、三节
- 范围：只做移动与场景；不做开火、不做敌人、不做伤害
- 验收：
  1. 启动 5 秒内进入可操作
  2. 按上下键，船在航道间移动，切换有延迟（数值 `@export`，默认 0.6 s）
  3. 换道过程中不能开火（此卡先留空实现）
  4. 稳定 60 fps，可正常退出
- 优先级：P0
- 依赖：无
- 交付：场景文件 + 参数说明

### T-002 手动瞄准开火 + 弹药消耗

- 目标：鼠标瞄准可发射炮弹，弹药数减少，打空后无法发射
- 依据：16 号文档 1.4；01 号文档第三节
- 范围：单种弹药、单种发射方式；不做弹种切换、不做命中伤害
- 验收：
  1. 按开火键/点鼠标，从船朝准星方向出弹道
  2. 每发扣 1 弹药，弹药为 0 时无弹道、无音效
  3. 弹药上限与回复速率走 `@export`（数值未定，先占位）
- 优先级：P0
- 依赖：T-001
- 交付：可运行分支

### T-003 碉堡自动索敌 + 开火

- 目标：敌人进入范围后碉堡自动开火，有射程可视化
- 依据：16 号文档 1.2；01 号文档第四节
- 范围：只做碉堡；敌人可先用占位方块
- 验收：
  1. 敌船进入射程即开火，离开即停
  2. 射程、射速、伤害走 `@export`
  3. 碉堡有血量字段（先不做受击逻辑）
- 优先级：P0
- 依赖：T-001
- 交付：可运行分支

### T-004 敌船推进与士气条

- 目标：敌船沿航道从右向左推进，被击沉后士气下降，士气归零判定本场胜利
- 依据：16 号文档 1.6、1.7
- 范围：单一敌船类型；不做 AI 走位、不做部位
- 验收：
  1. 敌船进入屏幕后匀速左移
  2. 击沉一艘，士气 −N（`@export`）
  3. 士气 ≤ 阈值时弹出"敌军撤退"并可结束本场
- 优先级：P0
- 依赖：T-002、T-003
- 交付：可运行分支

### T-005 部位血量与三档状态（先做舰体与帆）

- 目标：船有独立部位血量，掉到阈值进入"破损/被破坏"，并产生对应 debuff
- 依据：16 号文档 1.4；01 号文档第四节
- 范围：舰体（血量）、帆（移速）；炮管与旗后续再加
- 验收：
  1. 舰体归零 → 判定击沉
  2. 帆进入破损 → 移速下降；被破坏 → 移速进一步下降
  3. 三档状态有可见变化（先可用颜色占位）
- 优先级：P1
- 依赖：T-001
- 交付：可运行分支

### T-006 经营场景骨架：顶栏 + 罗盘 + 文本 + 选项

- 目标：能从战斗切到经营画面，看到资源栏、罗盘、剧情文本、选项，点选项后资源变化
- 依据：16 号文档第二节；13 号文档
- 范围：只做常规经营一个事件；不做记账本、不做升级/修理界面
- 验收：
  1. 顶栏显示材料/弹药/研究点/灯火/日历/船等级/堡等级
  2. 罗盘可点击或拖动选中选项，指针跟随
  3. 选项旁显示物资预测（材料++ / 灯火+）
  4. 选中后资源按预测变化
- 优先级：P1
- 依赖：T-001（切换入口）
- 交付：可运行分支

### T-007 数据层：资源与状态持久化

- 目标：材料、三种弹药、研究点、灯火档位、战船/碉堡等级与破损度、日历、失败次数，跨场景保存
- 依据：16 号文档 2.2、1.2
- 范围：只做内存与存档；不做 UI
- 验收：
  1. 战斗结束进入经营，数值不丢
  2. 退出重进能恢复（本地存档）
  3. 所有数值可在调试面板查看/修改
- 优先级：P0
- 依赖：无（可与 T-001 并行）
- 交付：autoload 单例 + 说明

### T-008 记账本

- 目标：记录每回合事件、选项、资源变化，可翻阅历史
- 依据：16 号文档 2.5
- 范围：只做展示；不做导出
- 验收：
  1. 战斗结束后的经营里能看到上一回合的记录
  2. 历史记录可按回合翻阅
- 优先级：P2
- 依赖：T-007
- 交付：可运行分支
