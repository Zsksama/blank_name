## 2. 只做了一点（留了接口）

### 2.1 船型 → 准星部位：规则写全了，数据只有一种

文档规则 9：**快船 → 帆；普通/重船 → 火器与弓手**。

- 现状：v0.1 只有一种敌船配置（倭船），M12 的三种船型还没落地，所以**目前实战里这条规则只有「普通船 → 火器」这一条生效**。
- 我加了字段 `EnemyShipConfig.ship_class`（枚举 `FAST / NORMAL / HEAVY`，默认 `NORMAL`）把规则写进去，三种船配置做好后**不用改代码**，填字段即可。
- 接口位置：`Scripts/Combat/enemy_ship_config.gd:12-14`、判定在 `Scripts/Combat/watchtower.gd` 的 `_part_for()`。
- **要改设计的话**：如果最终三型不按「快/普通/重」命名，把枚举改成对应名字即可，只动这一处。

### 2.2 +50% 的作用范围：接了「所有伤害」，但有两处没定

- 现状：通过 `ShipCombat.damage_taken_multiplier` 统一乘进**所有扣血入口**（玩家弹道、堡炮、接舷战 raw 伤害）。
- 于是有两条溢出影响，需要你拍板（P1、P2）：
  - 被锁的船同时也会被**堡炮**打得更疼 → 堡的实际输出凭空 +50%；
  - 被锁的船在**接舷战**里掉血也 +50% → 玩家贴上去打变得更划算。
- 接口：`Scripts/Combat/ship_combat.gd`（`damage_taken_multiplier`），要限定来源我加个参数就行。

### 2.3 接舷期间「锁定冻结」：只做了冻结，没做画面适配

- 现状：接舷一开，望楼不换目标、不重锁、准星不动（严格照规则 10）。
- 没做：接舷时镜头会**放大 + 位移**，准星是**世界坐标**画的，可能被推到画面外或被拉得很大——接舷镜头里基本看不到它，等于接舷时这个信息是丢的。
- 待定（P5）：接舷期间准星要不要隐藏 / 改成 HUD 上的小图标。

### 2.4 望楼「在堡上」这件事：只有逻辑，没有视觉锚点

- 现状：望楼是挂在 `BattleManager` 下的纯逻辑节点，堡顶没有任何东西表明「这里有望楼」。
- 影响：玩家无法把「+50%」和「堡顶」联系起来，只会觉得「有时候打得更疼」。
- 见建议 S1。

## 3. 实现口径与偏差（3 条，都是文档没写死的地方）

### 3.1 「最快」按实际速度算，不按配置速度

用的是 `EnemyShip.current_speed()`（含帆破损后的减速）。所以一艘帆被打烂的快船会**掉出锁定**，换给下一艘。判断依据是规则 2「始终锁最快的」，但如果你的意图是「锁最难缠的」，那应该按威胁度（火力 × 血量）而不是速度 —— 见 P3。

### 3.2 「整船 +50%」是从受伤侧实现的

不是给每发炮弹加伤，而是给**被锁的那艘船**挂一个倍率。好处是：玩家、堡炮、接舷三种来源自动都生效、数值只有一个来源；代价是没法区分来源（见 P1/P2）。

### 3.3 「退场」用坐标近似

规则 6 要求「沉没 / 中途退场」都立刻重锁。沉没是真事件；**退场**目前没有事件，我用 `x > 1360`（出生点 1330 再往右 30）当作「跑出画面且不回来」。等 M13 有真实退场状态，换成监听即可。

## 4. 优化与建议

按「对玩家体验影响」排序，前两条我建议做，后面的是可选。

**S1（建议做）给被锁的船一个「被盯上」的视觉标记。**
现在只有准星，而且准星很小、在船身上，玩家在混战里很容易看不见。建议给被锁船加一层很淡的外发光/描边（同一套色相 黄→红），或者 HUD 加一行字：`望楼：锁定 倭船 +50%`。
成本低（一个 shader 参数或一行 Label），收益是「望楼存在感」从无到有。

**S2（建议做）把望楼和玩家的准星区分开。**
画面上现在有两个「十字」：鼠标准星（打哪儿）和望楼准星（打谁）。形状接近，玩家会以为是同一个东西。建议二者形态拉开：鼠标准星做细十字 + 小圆点，望楼用「四段弧 + 四角短线」并且在准星旁挂一个小标签（如「帆」）。

**S3（可选）换锁加 0.1~0.2 s 的过渡。**
现在是旧目标一死，下一帧就跳到新目标，+50% 也跟着跳。加一个 0.15 s 的淡出/淡入会稳很多，也不会让玩家觉得「加成忽闪」。

**S4（可选）望楼对「同一艘船」的锁定加个最短保持时间（如 2 s）。**
现在只要出现更快的船就立刻换锁。如果后面快船成批出现，望楼会疯狂跳目标，观感很差。

**S5（可选）把「快船」的判据从船型改成速度阈值。**
如果 M12 最后不做三种船型（只有一种倭船 + 速度随机），那规则 9 的「快船」可以直接判定为「当前速度 ≥ X px/s」，这样不依赖新数据。等 M12 定了再决定，二者可以并存（船型优先，没填就用速度）。
