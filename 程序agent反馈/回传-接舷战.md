## 2. 逐卡明细

### 2.1 T-401 触发与判定

**已实现**

- 同航道 + 两船碰撞箱相交 / 间距 ≤ `boarding_distance`（**10 px**，占位）
- 三种进入方式（敌船贴上来 / 玩家主动撞 / 换道重叠）走同一个 `try_engage()` 入口
- 进入的同一帧结算一次撞击伤害
- 同一对船 `boarding_cooldown = 3 s`；接舷进行中不再触发
- 进入时记录快照：双方舰体血量、撞角耐久、是否换道重叠（4 个变量 + 1 个 bool）

**与文档的偏差（2 处，都是实测后改的）**

1. **删掉了「或中心距 ≤ 40 px」**。实测中这条会绕过竖直方向的重叠判断：玩家在一道、敌船在下一道，只要 X 对齐就会进接舷（截图给过天羽）。现在只认「碰撞箱真的相交」，竖直方向必须有重叠。
2. **新增硬门槛：任一方换道未结束，不许进接舷**。原因同上——换道途中两船卡在两条道中间，接舷镜头里两船是斜着的。现在换道中只记录、不触发，等双方都落到本道里再结算。

**边界确认**：敌船之间重叠不触发 ✅；已沉没的船不参与 ✅；接舷中玩家沉 → 走失败 ✅

**验收**

- [x] 贴着敌船能进入接舷
- [x] 接舷中反复贴不重复触发
- [x] 结束 3 s 内再贴不触发
- [x] 两艘敌船叠在一起不触发
- [x] 跨航道接触不触发（新增）

### 2.2 T-402 撞击伤害

**已实现**

- `伤害 = 相对速度 × 吨位比 × (撞角剩余比例 × 0.7) × k`，**双方各算一次**
- 撞角三档已接 M4：完好 ×1.0 / 破损 ×0.5 / 被破坏 ×0（直接撞不出伤害）
- 换道重叠走固定 **5** 伤（`lane_overlap_damage`，可在编辑器调）
- 撞沉了就直接走击沉，不进接舷
- 相对速度 < **80 px/s** 算轻碰：0 伤

**与文档的偏差（3 处）**

1. **k = 0.05（占位）**。按文档字面（`相对速度 × 吨位比 × 撞角减伤 × k`）取 k=1，100 px/s、撞角完好能撞出 **70 伤**，直接把 40 血的敌船撞沉。现在这个值把量级压到「一次正面撞 = 舰体的 5%~10%」。
2. **撞角损耗按「最大耐久的 20%」实现**（撞角 max 40 → 每次 −8，单次上限 30% = 12）。文档写的是「损失 0.2（上限 0.3）」，如果按**绝对点数**理解，等于每次只掉 0.2 点耐久，撞几十次才见底，因此按比例理解——**这条请你确认**。
3. **新增：侧面蹭 vs 正面撞的判定**（文档没写，天羽口头加的规矩）：
   - 碰撞发生时只要有一艘船还在换道 → 「侧面蹭」：固定 5 伤、**不磨撞角**
   - 双方都落位、正常往前顶 → 「正面撞」：走公式、磨 20% 撞角
   - 都落位但合速度 < 80 → 轻碰：0 伤、**不磨撞角**

> 关于「用重叠面积 / 左右侧区分」：侧视角下两船只要在同一航道，碰撞箱在竖直方向是**完全重叠**的，重叠区永远是「上下满高、左右很窄」的条，跟接触位置无关。能区分的是「它们是怎么靠到一起的」，所以用换道状态 + 合速度做判据。

**验收**

- [x] 撞角完好 vs 破损，同速伤害明显不同（4.20 / 1.26）
- [x] 双方都掉血
- [x] 撞完撞角掉 20%（40 → 32）
- [x] 换道重叠只掉固定 5，且可调
- [x] 侧面蹭不掉撞角（3 种接触实测见第 6 节）

### 2.3 T-403 接舷过程

**已实现**

- 进入即 `Engine.time_scale = 0.03`，接舷自身计时用真实时间（`set_ignore_time_scale`）
- 我方输出 = 战力 12 × 灯火系数 × qte_mult；敌方输出 = 战力 10 × 气焰系数
- 每秒：双方舰体互扣；其余部位扣「舰体伤害 × 30%」
- 部位血量下限 0；舰体归零即结束
- 接舷期间不能开炮、不能换道（复用 `controls_locked`）

**注**：灯火系数四档（1.2 / 1.0 / 0.8 / 0.6）与气焰四档已实现，但**只有 1.0 与 0.75 两档能实测**——灯火值战斗中没有变化来源（掉灯火逻辑在堡那边），气焰本体在 M14。

### 2.4 T-404 QTE 与逃跑

**已实现**

- 屏幕底部提示「接舷战！连按空格提升倍率 ×N　长按 T 撤退」
- `qte_mult` 初值 1.0，范围 **[1.0, 1.5]**
- **按一次空格 +0.01**；每 0.3 s 自然 −0.01
- 长按 **T 1.5 s** 逃跑，逃跑不中断

**与文档的偏差**：文档写「每按一次 +0.01」，我第一版做成了「按住每 0.08 s +0.01」（等于按住空格就能涨），已改回**真按键边沿检测**，现在必须连点。

## 5. 需要主策划拍板的 8 件事

1. **k 值**：现在 0.05（一次正面撞约 5~10 点舰体）。按文档字面 k=1 会撞出 70 伤，直接撞沉。要么给 k，要么给「一次撞击应占总血量几成」。
2. **撞角损耗口径**：是「最大耐久的 20%」还是「绝对值 0.2 点」？我按前者做的。
3. **气焰四档映射**：现在是 ≥75 → 1.2 / ≥25 → 0.9 / ≥−25 → 0.75 / 更低 → 1.3。那个 **1.3** 我按「崩溃反扑」理解的，对不对？
4. **侧面蹭 / 正面撞的判定规则**（新增，2.2 第 3 点）：认可还是改成别的口径？
5. **轻碰（< 80 px/s）是否仍进接舷**：文档写「伤害按 0 处理（仍会进接舷）」，我按这个实现了。要不要改成「不进接舷」？
6. **逃跑后退 200 px 会被海界夹住**：贴着堡打的时候退不动，要不要改成沿着航道往后滑或提速？
7. **接舷期间堡血条要不要可见**：现在一并隐藏了。
8. **快照（T-401-5）的用途**：现在只记录、写日志，没有参与任何结算——文档没写它给谁用（结算界面？战后修复？）。
